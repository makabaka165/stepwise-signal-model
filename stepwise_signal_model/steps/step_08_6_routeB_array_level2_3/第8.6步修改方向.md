### 1. 为什么 equal-phase rank1 过于理想

说明当前 V0：

c_p = b_p(theta1) + b_p(theta2)

等价于：

beta = 1
phi = 0
rho = 1

并结合第七部分结果说明：

- beta=0.3/0.1 失败；
- phase=150/180 deg 失败；
- 大俯仰差失败；
- el_assumed 较大误差失败。

### 2. 广义相干双源模型

写出：

y(t) = b(theta1,e1;e0)s1(t) + b(theta2,e2;e0)s2(t) + n(t)

Rs =
[ P1, rho*sqrt(P1*P2)*exp(j*phi);
  rho*sqrt(P1*P2)*exp(-j*phi), P2 ]

R_FB_model =
FBSS{ B Rs B^H + sigma2 I }

### 3. 模型层级

写清楚：

V0 equal-phase rank1:
P1=P2, rho=1, phi=0

V1 complex-gain rank1:
rho=1, q=sqrt(P2/P1)*exp(j phi)

V2 constrained covariance fitting:
0<=rho<=1, Rs PSD

V3 2D az/el coherent covfit:
用于大俯仰差和俯仰先验不可靠场景

### 4. 本轮只实现 V1

说明本轮只做：

covfit_rank1_complex_gain

目的是修复第七部分暴露出的幅度比和固定相位偏置问题。

## 四、complex-gain 模型公式

沿用层次二一维合成后的 65 列数据。

对候选角度 pair：

theta1 < theta2

和复增益：

q = beta * exp(1j*phi)

定义每个方位子阵：

b_p1 = S_p b(theta1)
b_p2 = S_p b(theta2)

c_p = b_p1 + q*b_p2

前向 rank1 模型：

G_F(theta1,theta2,q)
=
(1/P_phi) sum_p c_p c_p^H

前后向模型：

G_FB =
0.5 * (G_F + J*conj(G_F)*J)

观测模型：

R_model =
alpha * G_FB + sigma2 * I

其中 alpha>=0, sigma2>=0。

对每个候选 theta1/theta2/q，用非负最小二乘或带截断的最小二乘估计 alpha 和 sigma2：

min_{alpha>=0,sigma2>=0}
|| R_obs - alpha*G_FB - sigma2*I ||_F^2 / ||R_obs||_F^2

输出：

theta1_hat
theta2_hat
beta_hat
phi_hat
alpha_hat
sigma2_hat
objective_best

## 十三、判断标准

### 情况 A：complex-gain 修复 beta 和 phase

如果：

beta=0.3 tol_abs01 >= 0.9
phase=150/180 tol_abs01 >= 0.9

则写：

complex-gain rank1 成功扩展了层次二完全相干模型的幅度/相位适用范围，应作为 V1 层次二主模型候选。

### 情况 B：修复 beta，但 phase 仍失败

写：

幅度失配可以通过 complex-gain 修复，但反相场景需要更细 phase grid、label-symmetric q 搜索或相位正则。

### 情况 C：修复 phase，但 beta 仍失败

写：

固定相位偏置可以通过 complex-gain 修复，但强弱目标不平衡需要 log-beta grid、目标标签对称处理或弱目标正则。

### 情况 D：complex-gain 在 beta=1/phase=0 时明显不如 equal-phase

写：

q 搜索引入额外自由度和错误极小值，不宜直接替代 V0，需要先改 q 估计策略。

### 情况 E：beta/phase 修复，但之前含俯仰差的 extreme cases 仍失败

写：

层次二 complex-gain 已解决一维幅相失配，但大俯仰差属于层次二压缩结构边界，后续应进入 V3 层次三。
