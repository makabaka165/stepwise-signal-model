## 五、必须实现的谱函数消融 route

本轮不再只做原来的四条 route，而是重点比较不同谱函数聚合方式。

对每个候选角 az，先构造所有子阵的分母：

```
d_p(az) = real(a_p' * En * En' * a_p)
```

如果考虑 backward：

```
d_b,p(az) = real((J*conj(a_p))' * En * En' * (J*conj(a_p)))
```

先实现 forward-only 和 FB 两组。

------

### route A：center_real

保留第一部分 route 2 作为对照。

```
P_center(az) = 1 / d_mid(az)
```

------

### route B：avg_den_forward

这是第一部分 route 3。

```
P_avg_den_forward(az)
=
1 / mean_p d_p(az)
```

------

### route C：avg_spectrum_forward

新增。

不要平均分母，而是平均每个子阵自己的 MUSIC 谱：

```
P_avg_spectrum_forward(az)
=
mean_p [1 / max(d_p(az), eps)]
```

目的：

检查“先平均分母再倒数”是否把双峰抹平。

------

### route D：min_den_forward

新增。

```
P_min_den_forward(az)
=
1 / min_p d_p(az)
```

目的：

看是否至少存在某些子阵对真实角度有较强分辨能力。

------

### route E：median_den_forward

新增。

```
P_median_den_forward(az)
=
1 / median_p d_p(az)
```

目的：

减弱坏子阵对平均分母的影响。

------

### route F：trimmed_avg_den_forward

新增。

对所有 d_p 排序，去掉最大 20% 和最小 20%，再平均：

```
P_trimmed_avg_den_forward(az)
=
1 / mean(trimmed d_p(az))
```

目的：

避免极端子阵支配谱函数。

------

### route G：avg_den_fb

这是第一部分 route 4。

```
P_avg_den_fb(az)
=
1 / mean_p [0.5*d_p(az)+0.5*d_b,p(az)]
```

------

### route H：avg_spectrum_fb

新增。

```
P_avg_spectrum_fb(az)
=
mean_p [
0.5/max(d_p(az),eps)
+
0.5/max(d_b,p(az),eps)
]
```

------

### route I：min_den_fb

新增。

```
P_min_den_fb(az)
=
1 / min_p [0.5*d_p(az)+0.5*d_b,p(az)]
```

## 七、评价指标

每条聚合 route 都要统计：

```
raw_success_rate
tol_success_rate_abs01
tol_success_rate_rel025
rmse_deg
rmse_valid_count
mean_num_peaks
degraded_rate
```

但本轮新增以下诊断指标：

```
single_subarray_two_peak_rate
single_subarray_best_tol_rate
aggregation_peak_loss_flag
```

定义：

1. `single_subarray_two_peak_rate`

对所有子阵单独谱，能找到两个峰的子阵比例。

1. `single_subarray_best_tol_rate`

如果某个子阵单独谱能在 tol 内命中目标，则记为 1，否则 0。统计 Monte Carlo 平均。

1. `aggregation_peak_loss_flag`

如果存在至少一个子阵单独谱有两个有效峰，但聚合谱只有一个峰，则记为 1。

这三个指标很关键。

如果：

```
single_subarray_two_peak_rate > 0
但 route B/G 只有单峰
```

说明平均方式抹掉了双峰。

如果：

```
single_subarray_two_peak_rate ≈ 0
```

说明问题不是平均方式，而是每个子阵本身也分不开。

## 九、判断标准

```
single_subarray_two_peak_rate 明显 > 0

```

下一步继续层次二谱函数优化。

------

### 情况 2：单子阵也基本单峰

如果发现：

```
single_subarray_two_peak_rate 接近 0
所有聚合方式也基本单峰
```

结论写：

“在完全同相、同俯仰、小间隔条件下，当前一维层次二 MUSIC 谱函数族无法形成双峰；问题不是简单平均方式导致，而是平滑后信号子空间和真实圆柱子阵流形的匹配不足。下一步应进入层次二的一维圆柱阵平滑协方差拟合。”

下一步才进入协方差拟合。

------

### 情况 3：avg_spectrum 或 min_den 明显改善

如果发现：

```
avg_spectrum_forward / avg_spectrum_fb / min_den_fb 明显优于 avg_den_fb
```

结论写：

“层次二仍有价值。当前改进方向应是谱函数聚合方式，而不是直接进入协方差拟合或层次三。”
