### route 3：covfit_rank1_equal_phase

本轮主路线。

模型沿用第四部分：

```text
R_model(theta1,theta2) = alpha * G_FB(theta1,theta2) + sigma2 * I
```

其中：

```
G_FB(theta1,theta2)
由 c_p = b_p(theta1) + b_p(theta2)
经 forward/backward FBSS 平滑得到
```

对每个 pair 用非负最小二乘估计：

```
alpha >= 0
sigma2 >= 0
```

## 四、必须新增偏差与 objective valley 指标

除了常规指标：

```
raw_success_rate
tol_success_rate_abs01
tol_success_rate_rel025
rmse_deg
degraded_rate
```

必须新增以下指标：

```
mean_pair_sep_est
std_pair_sep_est
mean_pair_sep_bias
mean_abs_pair_sep_error
mean_pair_center_est
std_pair_center_est
mean_pair_center_bias
mean_abs_pair_center_error
objective_true_rank_median
objective_true_rank_p90
objective_margin_true_vs_best
objective_valley_sep_width_mean
objective_valley_center_width_mean
```

定义：

1. `pair_sep_est`

```
theta2_est - theta1_est
```

1. `pair_sep_bias`

```
mean(pair_sep_est - theta_sep_true)
```

1. `pair_center_bias`

```
mean((theta1_est+theta2_est)/2 - true_center)
```

1. `objective_margin_true_vs_best`

```
objective_true_pair - objective_best
```

如果 true pair 是最小值附近，这个值应接近 0。

1. `objective_valley_sep_width`

在 refine grid 中，找出：

```
objective <= objective_best * (1 + 0.05)
```

对应的 pair separation 范围宽度。

如果这个宽度很大，说明 separation 方向不可辨或低谷太平。

1. `objective_valley_center_width`

同理，统计 center 方向低谷宽度。

## 九、判断标准

### 情况 A：rank1 在 sep=10 上稳定高成功，且 sep bias 可控

如果：

```
covfit_rank1 sep=10 的 SNR90_abs01 <= 24 dB
且 mean_abs_pair_sep_error < 0.08 deg
```

则写：

```
rank1 equal-phase covfit 是层次二当前主算法候选。
```

下一步可以做更大范围 fullscan 或论文整理。

### 情况 B：rank1 成功率高，但 pair separation bias 大

如果：

```
tol_abs01 高
但 mean_abs_pair_sep_error 大
或 objective_valley_sep_width 大
```

则写：

```
rank1 covfit 能稳定定位两个目标在绝对容差内，但 separation 方向低谷较宽，需要加入间隔正则或更细的 pair constraint。
```

下一步仍在层次二内做正则化，不进入层次三。

### 情况 C：rank1 只在 Δφ=0 有效，非零 phase offset 退化

如果 phase_offset 增大后：

```
rank1 tol 明显下降
而 MUSIC 基线不下降或上升
```

则写：

```
rank1 equal-phase 是极端完全同相模型的专用解法。后续需要实现 rank1 phase-scan covfit。
```

下一步做：

```
covfit_rank1_phase_grid
```

仍然是层次二，不进入层次三。

### 情况 D：rank1 在 K/SNR 小扫描中不稳定

如果成功率对 K 或 SNR 异常敏感，则写：

```
当前 rank1 covfit 还只是 proof-of-concept，需要优化 pair search、objective normalization 或约束。
```
