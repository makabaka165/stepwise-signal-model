## 三、理论模型

沿用层次二一维合成后的 steering。

先生成 65×32 圆柱阵数据，然后用 el_assumed=0 做 32 层相干合成，得到：

y(t) ∈ C^{Q×1}, Q=65

对 y(t) 做方位 FBSS，得到观测平滑协方差：

R_obs = R_FB

其中：

Rxx = y*y'/T
R_F = (1/P_phi) sum_p S_p Rxx S_p^H
R_FB = 0.5*(R_F + J*conj(R_F)*J)

候选方位角 pair：

theta = [theta1, theta2], theta1 < theta2

真实圆柱一维合成 steering：

b(theta_i) ∈ C^{Q×1}

第 p 个方位子阵：

b_{p,i} = S_p b(theta_i)

构造：

B_p(theta) = [b_{p,1}, b_{p,2}]

前向模型：

R_model_F(theta, Rs, sigma2)
=
(1/P_phi) sum_p B_p(theta) Rs B_p^H(theta)
+
sigma2 * I

前后向模型：

R_model_FB(theta, Rs, sigma2)
=
0.5 * (R_model_F + J*conj(R_model_F)*J)

拟合目标：

min_{theta1,theta2,Rs,sigma2}
|| R_obs - R_model_FB(theta,Rs,sigma2) ||_F^2 / ||R_obs||_F^2

其中 Rs 是 2×2 源协方差。

## 四、必须实现的 covfit route

本轮至少实现 4 条 route：

### route 1：center_real baseline

沿用第三部分的 center_real，作为 MUSIC 谱函数族基线。

### route 2：min_den_fb baseline

沿用第三部分的 min_den_fb，作为子阵选择类 MUSIC 基线。

### route 3：covfit_rank1_equal_phase

假设两个源完全同相、等幅，即：

s1(t)=s(t)
s2(t)=s(t)

则合成 steering 为：

c_p(theta) = b_{p,1} + b_{p,2}

前向模型：

G_F(theta)
=
(1/P_phi) sum_p c_p c_p^H

前后向：

G_FB(theta)
=
0.5*(G_F + J*conj(G_F)*J)

模型：

R_model = alpha * G_FB(theta) + sigma2 * I

对每个候选 pair theta，用最小二乘估计 alpha 和 sigma2：

min_{alpha>=0, sigma2>=0}
|| R_obs - alpha*G_FB - sigma2*I ||_F^2

这条路线最贴合当前仿真中的完全同相信号。

### route 4：covfit_hermitian_lsq

使用一般 2×2 Hermitian 源协方差：

Rs =
[ c11, c12
  conj(c12), c22 ]

其中：

c11, c22 为实数，c12 = a + j b

模型可以写成：

R_model
=
c11*G11
+
c22*G22
+
a*(G12+G21)
+
j*b*(G12-G21)
+
sigma2*I

其中：

Gij(theta)
=
FBSS 后的平均基矩阵：
0.5 * [
(1/P) sum_p b_{p,i} b_{p,j}^H
+
J * conj((1/P) sum_p b_{p,i} b_{p,j}^H) * J
]

对每个候选 pair theta，用 real least squares 估计：

x = [c11, c22, a, b, sigma2]^T

拟合时使用：

A_real = [real(vec(G11)), real(vec(G22)), real(vec(G12+G21)), real(vec(1j*(G12-G21))), real(vec(I));
          imag(vec(G11)), imag(vec(G22)), imag(vec(G12+G21)), imag(vec(1j*(G12-G21))), imag(vec(I))]

y_real = [real(vec(R_obs)); imag(vec(R_obs))]

x = A_real \ y_real

然后记录：

- sigma2 是否为负；
- Rs 是否 PSD；
- 如果 Rs 非 PSD，做 PSD 投影后重新计算 score。

输出两种 score：

1. `score_lsq_unconstrained`
2. `score_lsq_psd_projected`

最终 route 4 可以先用 PSD-projected score 作为主结果，但要记录 unconstrained 结果。

## 五、候选 pair 搜索方式

不要做过大的 fullscan。先做小规模 pair fitting 诊断。

参数：

```matlab
Q = 65;
K_phi_list = [20, 24];
sep_factor_list = [7, 10];
snr_list = [24, 28, 30];
Metkl = 50;
T_snap = 260;
angle_step_coarse = 0.02;
angle_step_refine = 0.005;
```

角间隔继续使用 65 列基线：

```
d_eq = 2*pi*cfg.arr.R/cfg.arr.Naz;
bw_eq_65 = 50.8 * 1.45 * cfg.arr.lambda / ((Q - 1)*d_eq);
theta_sep = bw_eq_65 / sep_factor;
theta_a = azCtr_deg - theta_sep/2;
theta_b = azCtr_deg + theta_sep/2;
```

pair search 不允许直接使用 true theta_sep 作为已知量。

候选 pair 设置：

```
angle_grid_coarse = azCtr_deg - bw_eq_65 : 0.02 : azCtr_deg + bw_eq_65;
min_pair_sep_deg = 0.05;
max_pair_sep_deg = 0.80;
```

只保留：

```
theta2 > theta1
min_pair_sep_deg <= theta2-theta1 <= max_pair_sep_deg
```

两阶段搜索：

1. coarse stage：
   - 对所有候选 pair 计算 covfit score；
   - 保留 score 最小的 top_N = 5 个 pair。
2. refine stage：
   - 对每个 top pair，在 theta1/theta2 附近 ±0.06 deg 范围内，用 0.005 deg 网格 refine；
   - 继续满足 theta2 > theta1 和 pair_sep 约束；
   - 取 score 最小 pair 作为估计。

必须记录：

- best coarse pair；
- best refined pair；
- objective value；
- true pair 的 objective value，仅作为诊断，不参与估计；
- true pair objective rank，如果可计算；
- estimated pair 与 true pair 的误差。

## 九、判断标准

### 情况 A：covfit_rank1_equal_phase 明显优于 center_real/min_den

如果：

```
covfit_rank1 tol_abs01 - center_real tol_abs01 >= 0.10
```

尤其在：

```
K_phi=20, sep=10, SNR=30
```

上成立，则写：

“层次二协方差拟合有效。完全同相小间隔场景中，pair covariance fitting 比 MUSIC 峰搜索更适合。”

下一步可以对 covfit 做更大规模 K/SNR 扫描，但仍不做层次三。

### 情况 B：covfit_hermitian_lsq 优于 rank1

如果 Hermitian LS 明显更好，写：

“一般源协方差拟合比固定完全同相模型更稳，但需要关注 PSD violation 和 sigma2 negative 问题。”

下一步优化 PSD 约束和正则化。

### 情况 C：covfit 与 center_real/min_den 持平

如果 covfit 不明显提升，但 objective map 在 true pair 附近有低谷，写：

“协方差拟合模型方向正确，但当前 pair search/约束/噪声条件不足以稳定提升。”

下一步改进 pair search 或 regularization。

### 情况 D：covfit 更差，且 true pair objective 不是低谷

如果 true pair objective 排名很差，写：

“当前一维层次二平滑协方差模型与观测 R_FB 不匹配，问题不只是峰搜索。需要重新检查 FBSS 后模型构造或考虑层次三。”

注意：即使出现情况 D，也不要直接实现层次三，只写建议。
