## 四、需要比较的 route

保留以下基线：

### route 1：center_real

只用中心子阵真实流形：

```
P_center(az)=1/d_mid(az)
```

### route 2：min_den_forward

第二部分中有效的 route：

```
P_min_den_forward(az)=1/min_p d_p(az)
```

### route 3：min_den_fb

```
P_min_den_fb(az)=1/min_p 0.5*(d_p(az)+d_b,p(az))
```

------

新增以下子阵选择/加权 route：

### route 4：center_window_3_avg_spectrum

只取中心附近 3 个子阵，例如：

```
p_mid-1 : p_mid+1
```

聚合方式：

```
P = mean_p 1/d_p
```

### route 5：center_window_5_avg_spectrum

只取中心附近 5 个子阵：

```
p_mid-2 : p_mid+2
```

### route 6：center_window_7_avg_spectrum

只取中心附近 7 个子阵：

```
p_mid-3 : p_mid+3
```

### route 7：center_window_9_avg_spectrum

只取中心附近 9 个子阵：

```
p_mid-4 : p_mid+4
```

### route 8：center_window_5_min_den

只在中心 5 个子阵中做 min-den：

```
P = 1/min_{p in center5} d_p
```

### route 9：center_window_7_min_den

只在中心 7 个子阵中做 min-den。

### route 10：gaussian_weight_avg_spectrum

按子阵中心离 0° 的距离做高斯权重：

```
w_p = exp(-(phi_center_p/sigma_phi)^2/2)
w_p = w_p / sum(w_p)
P = sum_p w_p * (1/d_p)
```

先固定：

```
sigma_phi = 6 deg
```

### route 11：gaussian_weight_den_then_inverse

```
P = 1 / sum_p w_p * d_p
```

同样先用：

```
sigma_phi = 6 deg
```

### route 12：oracle_best_subarray_upper_bound

这个 route 只作为理论上限，不作为工程算法。

对每个 Monte Carlo 样本，遍历所有单子阵谱，如果有某个子阵能在 tol_deg 内命中，则记成功。

它不用于最终算法，但用于回答：

“如果能正确选择子阵，层次二理论上最高能到多少？”

## 七、判断标准

### 情况 A：某个中心窗口或高斯加权 route 明显优于 center_real/min_den

如果：

```
best_route_minus_center_real >= 0.05
且 best_route_minus_min_den >= 0.05
```

则写：

“层次二继续有效，下一步围绕该 route 做更大规模 K_phi/SNR 扫描。”

此时仍不做协方差拟合。

------

### 情况 B：所有加权/窗口 route 都和 center_real/min_den 持平

如果：

```
best_route_minus_center_real < 0.05
且 best_route_minus_min_den < 0.05
```

则写：

“中心子阵真实流形已经基本达到当前层次二 MUSIC 谱函数族上限，进一步聚合收益有限。”

下一步有两个选择：

1. 如果 oracle_best_subarray_tol_rate 明显高于 center_real，则继续做“子阵选择判据”；
2. 如果 oracle_best_subarray_tol_rate 也不高，则进入层次二协方差拟合。

------

### 情况 C：oracle 上限明显高于所有实际 route

如果：

```
oracle_best_subarray_tol_rate - best_actual_route_tol >= 0.10
```

则写：

“层次二的关键不是谱函数形式，而是如何从多个子阵中识别有效子阵。”

下一步做“子阵选择判据”，例如用 peak-to-valley、峰间距、谱峰对称性、子阵中心角权重来选择。

------

### 情况 D：oracle 上限也很低

如果：

```
oracle_best_subarray_tol_rate < 0.40
```

则写：

“在当前完全同相、同俯仰、sep=10 边界下，层次二一维 MUSIC 谱函数族的理论上限也有限。”

下一步进入层次二协方差拟合，仍不进入层次三。
