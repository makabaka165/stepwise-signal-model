# Step11.6 Shared-Center Rotatable Beamspace Manifold Cache

中文创新点：基于 shared-center 圆柱阵旋转等价性的可复用波束域流形缓存方法。

English name: Shared-Center Rotatable Beamspace Manifold Cache for Cylindrical-Array Beamspace ML.

## Goal

Step11.6 keeps the Step11 controlled pair2d beamspace ML score unchanged:

`Y = A_cyl(Theta)S + N`, `Z = W'Y`, `G(Theta)=W'A_cyl(Theta)`, and `J(Theta)=trace(P_G Z Z')`.

It only replaces repeated steering/manifold construction with a reusable canonical beamspace cache `G_cache(delta_az,el)=W'A_cyl(delta_az,el)` under shared-center cylindrical-array rotation equivalence.

## Relation To Step11.5

Step11.5 C05 solves "search fewer candidates" with adaptive topK/window selection. Step11.6 solves "compute candidate manifolds faster" by exact canonical cache lookup. It does not change Step11.5 C05 parameters, policy logic, candidate sets, or ML scoring.

## Rotation Equivalence

For a shared-center local subarray,

`r_m(theta_c)=R_z(theta_c)r'_m`

and

`u(theta_c+delta,el)=R_z(theta_c)u(delta,el)`.

Thus

`r_m(theta_c)^T u(theta_c+delta,el) = r'_m^T u(delta,el)`.

With canonical 65-column by 32-layer local order and a W built for that same order, the actual-center steering vector and `W'a` beamspace manifold can be reused from a canonical local delta-azimuth cache.

## Pass Criteria

Stage1 passes only if max non-phase-aligned `rel_a_error <= 1e-8` and max `rel_G_error <= 1e-8`.

Stage2 passes only if direct and cached searches have same estimate rate 1, same policy rate 1, max relative score difference `<= 1e-8`, zero cache misses, matched success, matched topK miss, and matched boundary hit for all trials.

Stage3 manifold runtime passes only if median manifold-time reduction is at least 0.50 and Stage2 passed. Total search runtime pass is reported but is not required for the Step11.6 overall pass.

Stage4 passes only if every tested center passes manifold equivalence, search consistency, and has zero cache miss.

Overall Step11.6 passes only if Stage1, Stage2, Stage4, and Stage3 manifold-runtime pass.

## Usage Boundary

The cache is valid only for shared-center canonical local order. Every actual working subarray must be reordered to the same 65-column by 32-layer order before lookup. W must match the canonical local order. If W embeds absolute global-coordinate assumptions, rotate/reorder W and revalidate before use.

Default lookup is exact grid lookup only. Interpolation is future work and is not used in passing results. If a grid point is missing, the implementation records a cache miss and falls back to direct precompute rather than silently interpolating.

## Thesis Use

If Step11.6 passes, write it as an engineering acceleration module for Step11.5 C05: it preserves the ML model, score, candidate set, and C05 policy, while reducing repeated manifold construction through shared-center rotation-equivalent canonical cache reuse.

If it does not pass, keep it as a negative engineering result: the current W/order/center mapping is not yet safe for default cached deployment, and Step11.5 C05 remains unaffected as the main algorithmic innovation.
