# Step13.2 DBF RTL Testbenches

Testbenches:

- `tb_dbf_complex_mac.v`: standalone hand-written checks for `conj(W) * Y`.
- `tb_dbf_core_accum.v`: compact golden-vector smoke for the raw DBF
  accumulator.

The accumulator testbench includes:

```text
../results_step13_fpga_soc_dbf_boundary/rtl_golden/step13_dbf_rtl_golden_vectors.vh
```

Run the smoke from the Step13 directory:

```bash
bash sim/run_iverilog_dbf_smoke.sh
```

The smoke writes a small CSV to:

```text
results_step13_fpga_soc_dbf_boundary/rtl_sim/dbf_core_accum_output.csv
```

No waveform file is generated by default.
