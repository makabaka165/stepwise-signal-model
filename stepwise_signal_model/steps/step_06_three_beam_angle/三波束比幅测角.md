# 三波束比幅测角

## 1. 当前中心束的主导区域

三波束比幅测角默认目标位于当前中心束附近。当前代码用中心束和相邻束的响应大小来限定 LUT 的有效工作区间：

```matlab
mainAz(i) = aC - max(aL, aR);
mainEl(i) = aC - max(aD, aU);
idxAz = find(mainAz >= 0);
idxEl = find(mainEl >= 0);
```

其中：

- `aC` 是中心束响应。
- `aL/aR` 是方位左/右邻束响应。
- `aD/aU` 是俯仰下/上邻束响应。
- `mainAz >= 0` 表示该方位扫描角仍由当前中心束主导。
- `mainEl >= 0` 表示该俯仰扫描角仍由当前中心束主导。

这一步的作用是排除已经更靠近相邻束中心或旁瓣的扫描角。三波束比幅测角只应该在当前中心束负责的角度范围内反查。如果目标已经进入相邻束主导区域，完整流程应把相邻束重新作为中心束，再构造新的三波束组。

因此，`mainAz/mainEl` 的判定不是说任意检测单元都能用当前中心束有效测角，而是说：

当前检测单元若确实来自当前中心束覆盖的目标，则只在 `mainAz/mainEl >= 0` 对应的中心束主导角度区间内构造反查 LUT。

对于不同的距离-Doppler 检测单元，也只有在其角度落入当前中心束主导区时，才适合继续以当前中心束作为中心做三波束测角。若该检测单元的目标实际更靠近左/右/上/下邻束，应重新选中心束。

## 2. 三波束如何构建 LUT

LUT 是扫描角度得到的 `rho-angle` 对照表。方位和俯仰分别构造。

方位扫描：

```matlab
azScan = linspace(locAz(1), locAz(3), 401);
```

对每个扫描角 `azScan(i)`：

```matlab
a = steer_vec_local(azScan(i), locEl(2), xVec, yVec, zVec, lambda);
aL = abs(beamW(:, 1)' * a);
aC = abs(beamW(:, 2)' * a);
aR = abs(beamW(:, 3)' * a);
rhoAzLut(i) = (aR - aL) / (aR + aL);
mainAz(i) = aC - max(aL, aR);
```

俯仰扫描：

```matlab
uScan = linspace(sind(locEl(4)), sind(locEl(5)), 401);
elScan = asind(uScan);
```

对每个扫描角 `elScan(i)`：

```matlab
a = steer_vec_local(locAz(2), elScan(i), xVec, yVec, zVec, lambda);
aD = abs(beamW(:, 4)' * a);
aC = abs(beamW(:, 2)' * a);
aU = abs(beamW(:, 5)' * a);
rhoElLut(i) = (aU - aD) / (aU + aD);
mainEl(i) = aC - max(aD, aU);
```

方位 LUT 的含义是：

```text
azScan  -> rhoAzLut
角度     -> 方位比幅量
```

俯仰 LUT 的含义是：

```text
elScan  -> rhoElLut
角度     -> 俯仰比幅量
```

## 3. 为什么要选单调支路

反查需要从实测 `rho` 得到角度：

```text
rhoIn -> angle
```

这要求 `rho(angle)` 在当前反查区间内是一对一的。如果曲线不单调，同一个 `rho` 可能对应多个角度，反查结果就不唯一。

所以代码先用 `mainAz/mainEl >= 0` 限制中心束主导区，再根据实测三波束幅度选择左支路或右支路：

- `amp3(3) > amp3(1)`：右/上邻束更强，目标在右/上支路。
- `amp3(1) > amp3(3)`：左/下邻束更强，目标在左/下支路。
- `amp3(1) == amp3(3)`：两侧邻束相等，`rho=0`，直接返回中心束角度。

选好方向后，从中心点向该方向走，直到 `rho` 的差分符号改变：

```matlab
dRho = diff(rhoLut(:));
```

差分符号不变，说明还在同一条单调支路；差分符号改变，说明曲线开始折返，应停止。这样得到的 `rhoBr` 和 `axBr` 就是用于反查的一段单调 LUT。

## 4. 如何进行线性反查

实测比幅量来自检测单元处的三波束幅度：

```matlab
rhoAz = (ampAz(3) - ampAz(1)) / (ampAz(3) + ampAz(1));
rhoEl = (ampEl(3) - ampEl(1)) / (ampEl(3) + ampEl(1));
```

选出单调支路后，得到：

```matlab
rhoBr  % 单调支路上的 rho
axBr   % rhoBr 对应的角度
```

反查时把 `rhoBr` 当作自变量，把 `axBr` 当作函数值：

```matlab
valEst = interp1(rhoBr, axBr, rhoLim, 'linear');
```

也就是构造：

```text
rho -> angle
```

如果 `rhoLim` 落在 `rhoBr(k)` 和 `rhoBr(k+1)` 之间，线性插值公式是：

```text
angle = axBr(k)
      + (rhoLim - rhoBr(k)) / (rhoBr(k+1) - rhoBr(k))
        * (axBr(k+1) - axBr(k))
```

`rhoLim` 是把实测 `rhoIn` 限制在当前支路范围内：

```matlab
rhoMin = min(rhoBr);
rhoMax = max(rhoBr);
rhoLim = min(max(rhoIn, rhoMin), rhoMax);
```

含义：

- `rhoIn < rhoMin` 时，取 `rhoMin`。
- `rhoIn > rhoMax` 时，取 `rhoMax`。
- `rhoIn` 在范围内时，保持不变。

这样做是为了避免噪声使实测 `rho` 稍微超出 LUT 范围，导致 `interp1` 返回 `NaN`。如果经常发生限幅，说明目标可能不在当前中心束的有效测角区间内，应该重新选择中心束或扩大/重建 LUT。
