# 相关工作笔记预留

## MUSIC 与子空间方法

说明传统 MUSIC、Root-MUSIC、ESPRIT 等子空间方法的基本假设，以及与本方法的局部阵列流形使用方式的差异。

## 相干源与空间平滑

整理相干源秩亏、空间平滑、前后向平滑和 rank-restoration 的常见处理。本文只采用最小必要的 rank1/common-el fallback，不扩展到一般相干源完整协方差拟合。

## 非均匀阵 / 圆阵 / 局部流形

说明圆柱阵、非均匀阵和局部阵列流形的 steering 建模。本文的特色是 coarseAz 吸附物理列后统一为 shared-center 65 列局部流形。

## 稀疏 / gridless / atomic norm 方法

预留稀疏恢复、gridless DOA、atomic norm 等路线对比。本文不采用这些方法作为主线，因为当前目标是前端约束下的保守增强测角。

## 深度学习辅助 DOA 方法

预留 DNN/Transformer/数据驱动 DOA 的相关工作。本文不依赖训练数据，也不把网络模型作为当前创新点。

## FPGA / SoC / DPU 部署边界

整理硬件加速、混合精度和 SoC 分工文献。本文只承诺可加速模块和决策模块分工，不承诺纯 FPGA 完整闭合。

## 与本文方法的区别

本文方法的区别是：前端检测状态驱动、shared-center 局部圆柱阵规范化、相干秩亏最小恢复和拒判优先级共同组成一个工程可落地但边界清楚的路线。
