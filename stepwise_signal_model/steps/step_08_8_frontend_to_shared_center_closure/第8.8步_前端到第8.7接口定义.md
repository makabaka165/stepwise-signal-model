# 第8.8步 前端到第8.7接口定义

## 1. 默认适用场景

第 8.8 默认处理 `single coarse peak / unresolved local cluster`：前端在某个距离-多普勒单元或局部角域中检测到一个粗峰，该粗峰可能对应一个真实目标，也可能包含两个相干或近邻空间分量。系统以该粗峰方位吸附最近实际阵元列，选择 65 列工作子阵，再进入第 8.7 shared-center lazy cascade。

若角度粗扫描已经出现两个稳定粗峰，则该场景不进入本文默认 shared-center 主线，而标记为 `multi-coarse-peak / out-of-scope`，交给前端多目标分支、上层跟踪、后续 CPI 调度或未来工作。本轮只标记状态，不实现 dual-center。

## 2. 前端输出 frontend_out

第 5/6 步前端输出以下基础字段：`rangeIdx`、`dopplerIdx`、`range_m`、`velocity_mps`、`coarseAz_deg`、`coarseEl_deg`、`coarseMetric`、`peakCountCoarse`、`coarsePeakWidth`、`coarsePeakProminence`、`selectedCenterColumn`、`selectedCenterAz_deg`、`selectedWorkColumns`、`cfarCount`、`cfarBestMetric`。

- `rangeIdx / dopplerIdx` 来自 MTD + CFAR。
- `coarseAz / coarseEl` 来自低成本粗方位 beamformer 和检测单元上的三波束比幅。
- `selectedCenterColumn` 是 `coarseAz` 吸附到最近实际阵元列后的中心列。
- `selectedWorkColumns` 是中心列左右各 32 列，总共 65 列，按圆柱阵列周期回绕。

第 8.8 状态整理新增字段：`coarse_peak_sep_deg`、`second_peak_prominence`、`frontend_state`、`in_scope_shared_center_flag`、`out_of_scope_reason`、`merge_candidate_flag`、`weak_secondary_candidate_flag`、`selected_center_valid_flag`。

## 3. 前端状态机

状态集合为：`single_peak_in_scope`、`two_close_peaks_merge_candidate`、`two_separated_peaks_out_of_scope`、`weak_secondary_candidate`、`no_valid_coarse_peak`。

- `single_peak_in_scope`：`coarse_peak_count == 1`，默认进入 shared-center 增强测角。
- `two_close_peaks_merge_candidate`：粗峰间隔小于 `merge_threshold`，当前只作为合并候选或未来验证状态；若原粗峰合并逻辑已经把它视作单粗峰，则仍可沿原 shared-center 路径验证。
- `two_separated_peaks_out_of_scope`：粗峰间隔不小于 `merge_threshold`，表示前端已有多目标迹象，不进入默认 shared-center 主线。
- `weak_secondary_candidate`：第二粗峰弱或不稳定，只作为低置信二级候选标签，不作为高置信双目标输出依据。
- `no_valid_coarse_peak`：CFAR 未形成有效检测或中心列无效。

`merge_threshold = min(1.5 deg, column_spacing_deg)`，当前 `column_spacing_deg = 1.875 deg`，因此 `merge_threshold = 1.500 deg`。

## 4. 第8.7 shared-center 输入 enhance_in

第 8.7 shared-center 增强测角输入：`Y_work`、`thetaCenter_deg`、`elAssumed_deg`、`rangeIdx`、`dopplerIdx`、`R_runtime_default_deg`、`R_runtime_expand_deg`、`template_R_deg`、`cfg`、`arrayInfo`。

- `R_runtime_default_deg = 1.5 deg`
- `R_runtime_expand_deg = 2.0 deg`
- `template_R_deg = 2.0 deg`
- `Y_work` 的尺寸为 `65 x 32 x T_snap`，本轮 `T_snap=Np=32`。

## 5. Y_work 构造

本轮优先使用 MTD 前慢时间快拍。理论形式为：

`Y_elem(:, p) = pcCube(:, rangeIdx, p)`

若目标有 Doppler，则按检测到的 Doppler bin 做去旋：

`Y_elem(:, p) = pcCube(:, rangeIdx, p) * exp(-j*2*pi*fd_hat*tSlow(p))`

随后按 `selectedWorkColumns` 抽取 65 列，并 reshape 为 `Y_work = [65, 32, T_snap]`。本轮脚本为节省运行时间，保存的是检测距离单元的阵元级快拍 `pc_like.Y_full_range`，它等价于 `pcCube(:, rangeIdx, :)`；完整全阵版本只需把该快拍替换为实际 `pcCube` 抽取。

## 6. 一次观测双空间分量模型

两个空间分量属于同一次观测、同一 CPI、同一距离-多普勒单元中的叠加：

`x(t) = a(theta1, el1) s1(t) + a(theta2, el2) s2(t) + n(t)`

`s2(t) = beta * exp(j*phi) * (rho*s1(t) + sqrt(1-rho^2)*v(t))`

- `rho=1` 表示完全相干，`rho<1` 表示部分相干。
- `beta` 表示幅度比，`phi` 表示固定相位差。
- 前端 LFM/脉压/MTD 将叠加信号定位到一个 RD 检测单元。
- 第 8.7 只作为该检测单元内的 shared-center 增强测角模块。

## 7. 推荐前端策略

- single coarse peak -> shared_center_enhancement
- two close coarse peaks -> merge_candidate_or_future_validation
- two separated coarse peaks -> front-end multi-target branch / out-of-scope
- weak secondary peak -> low-confidence secondary candidate

## 8. 第8.8B Doppler de-rotation接口结论

第 8.8B 对同一份观测、同一 `frontend_out`、同一 65 列工作子阵比较了三种 `Y_work` 构造：

- `no_derotation`
- `derotation_minus`: `exp(-j*2*pi*fd_hat*tSlow(p))`
- `derotation_plus`: `exp(+j*2*pi*fd_hat*tSlow(p))`

正式结果为 `Metkl=30`、`quick_mode=0`、`in_scope_trials=1320`。三种模式的 success、route、confidence、false-high、boundary-missed 和 az/el 输出均一致：

- `success_no_derotation = 0.486364`
- `success_derotation_minus = 0.486364`
- `success_derotation_plus = 0.486364`
- `route_agreement_minus_vs_no = 1`
- `route_agreement_plus_vs_no = 1`
- `confidence_agreement_minus_vs_no = 1`
- `confidence_agreement_plus_vs_no = 1`
- `false_high = 0`
- `boundary_missed = 0`

因此当前第 8.8 shared-center 默认场景下，Doppler de-rotation 对第 8.7 lazy cascade 输出影响很小。接口中保留以下可选字段用于工程严谨性和后续平台一致性检查：

- `enhance_in.derotation_mode`
- `enhance_in.fd_hat`
- `enhance_in.v_hat`
- `enhance_in.fd_hat_source`
- `enhance_in.derotation_sign_used`

但当前不建议把 Doppler de-rotation 强制设为默认步骤。推荐：

`recommended_ywork_mode = no_derotation_or_optional_derotation`

`recommend_enable_derotation_flag = 0`

若后续硬件或实测数据需要启用 de-rotation，应优先使用 `fd_hat = fdAxis(dopplerIdx)`，并重新用实测 MTD 轴、速度符号和 echo 相位约定闭合 sign。
