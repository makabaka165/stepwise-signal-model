## 一、当前瓶颈分析

从第 8 步的所有失败原型 (proto1 ~ proto5a-refined2) 已经把瓶颈定位清楚：

1. **不是 FFT 中心估计的问题**：proto4 / 4a / 4b / 4e 各种 FFT 中心 / 窗口修补，在 `proto4_line_fair_compare` (seed 锁定，同样本) 下 SNR90 都没真正超过真值中心 baseline。所以「沿 FFT 引导窗口」这条线本身上限有限，已经触顶。
2. **不是协方差残差对消能解的**：proto3 直接劣化到全零。相干双目标的 Rss 是秩 2 但两个特征向量在 beamspace 下高度耦合，单峰秩 1 强对消会把共享结构打掉。
3. **不是 FFT-II 论文复现能直接拯救**：proto5a / 5a-refined / 5a-refined2 三轮都没把残差里的次目标稳定显露出来。论文 (4-14)~(4-19) 那套泄漏建模在相干等幅、间隔小于 1 个波束宽度的场景里，第一次主峰对消后残差里的次峰几乎都是旁瓣泄漏而非真目标。
4. **真正暴露出来的金线索**：在 `proto5a` 里顺手做的 `root_music_reference`（FBSS 后直接 Root-MUSIC）在同 seed 公平对比下系统性领先 Route B 主线 2 dB：

| 角间隔 | Route B (baseline_true_centerT) | Root-MUSIC (FBSS + root) | 差距 |
| ------ | ------------------------------- | ------------------------ | ---- |
| bw/7   | 16 dB                           | **14 dB**                | -2   |
| bw/8   | 18 dB                           | **16 dB**                | -2   |
| bw/9   | 22 dB                           | **20 dB**                | -2   |
| bw/10  | 24 dB                           | **22 dB**                | -2   |

也就是说整个 SNR90 曲线被整体下移 2 dB，且不依赖 FFT 中心、不依赖任何启发式窗口。这条线索几乎已经是论文创新点的现成答案 —— 只是它目前在 `proto5a_refined2` 里被当作参考线而不是创新点。

## 二、创新方向总览

按论文价值 × 实现难度排序。

### 方向 A（最优先，几乎稳赢）：把后端从 grid-MUSIC 换成 Root-MUSIC

核心改动只有一处：Route B 的「1D MUSIC 网格搜索 + 局部峰检测」换成「在 FBSS 后的协方差上做多项式求根 (Root-MUSIC)」。

- **原理**：Root-MUSIC 把谱峰搜索变成 `2(K-1)` 阶多项式求根，避开网格量化、避开峰提取启发式（这是 proto3 / proto5 失败的另一个隐藏代价：peak picking 在双峰即将合并时极不稳定）。
- **两个子版本**：
  - **A-array**：在 `Rss (K_fbss × K_fbss)` 上直接 Root-MUSIC（已被 proto5a 验证）
  - **A-beamspace**：在 `Rb (M_b × M_b)` 上做 Beamspace Root-MUSIC（Zoltowski 等的做法）。`Tk = QR(Wcenter)` 是近似酉矩阵，对应的 beamspace steering `b(θ) = Tk' * a(θ)` 仍是 K 个空间频率分量的线性组合，可走 "Root-MUSIC in Beamspace"。
- **预期收益**：把 Route B 整体 SNR90 下移 2 dB（A-array 已经被实验证实）。
- **论文表述**："Array-domain FBSS Combined with Beamspace Root-MUSIC for Coherent Targets"。

> 这是最该立刻拿来当主创新点的方向，几乎零风险，已有公平实验背书。

### 方向 B（次优先，论文里非常成熟）：在 FBSS 之上加 Toeplitz 结构投影

核心改动：在 `mssp_array_fb` 输出的 `Rss` 上再做一次 Toeplitz 平均（或 Toeplitz 投影），再喂给后端。

- **原理**：ULA + 时间平稳模型下，真协方差 R_ss 严格 Toeplitz；有限快拍 + FBSS 残留的非 Toeplitz 分量纯粹来自噪声。强制 Toeplitz 化等于多做一次免费平均，能进一步降低 R_ss 第二特征值附近的扰动方差。
- **实现**（待方向 A 跑通后引入）：

  ```matlab
  function R_t = toeplitz_project(R)
      K = size(R, 1);
      r = zeros(K, 1);
      for k = 0:K-1
          r(k+1) = mean(diag(R, k));
      end
      R_t = toeplitz(r);
      R_t = 0.5 * (R_t + R_t');
  end
  ```
- **预期收益**：在 `bw/8 ~ bw/10` 这类 `lambda2/noise_floor ≈ 1` 的区域，能再压 1 ~ 2 dB。
- **可叠加性**：可以叠加在方向 A 上 ⇒ "Toeplitz-FBSS + Beamspace Root-MUSIC"，论文上是一个干净的组合创新点。

### 方向 C（论文常见，但有上限）：把酉变换 / Unitary 处理引入 Route B

核心改动：用酉变换 `Q` (Lee 1981) 把复数 `R_b` 变成实对称矩阵，再做实数特征分解 + 实 Root-MUSIC。

- **原理**：酉变换天然把 forward-backward 平均内置进了实数化，等效再做一次 FB 平均，并且实数 eig 比复数 eig 在小快拍下数值更稳定。
- **预期收益**：和方向 B 量级类似，能再压 1 ~ 2 dB；比方向 B 略弱，但论文上 "Unitary X-MUSIC / Unitary ESPRIT" 是很标准的写法，文献多、好引用。

### 方向 D（如果想把 FFT-II 那条线救回来）：把 RELAX 用在 Route B 的子空间上，而不是 FFT 域

proto5 那套 FFT-II 失败的原因已经在第 8 步实验记录里定位：FFT 域的主峰对消显露不出真次峰。但 RELAX 思路 (Li & Stoica) 本身没错，只是不该在 FFT 谱上做，而应该在 Route B 已经稳定的子空间上做。

- **核心改动**：
  1. 用 Route B 给出 `(θ_1^{(0)}, θ_2^{(0)})` 作为初值
  2. 固定 `θ_2`，在阵元域对 y 直接做最小二乘对消 `y' = y - a(θ_2) * β_2`
  3. 在 y' 上重做 FBSS + Root-MUSIC，更新 `θ_1`
  4. 角色互换，更新 `θ_2`
  5. 迭代到收敛
- **跟 proto3 的区别**：proto3 在 beamspace 协方差上做秩 1 强对消，会破坏双目标共享结构；这里在阵元域 y 上做对消，FBSS 仍然完整作用在新 y' 上，没有破坏 FBSS 的解相干前提。
- **预期收益**：在中高 SNR 区可能再压 1 dB；论文创新点表述 "Subspace-domain RELAX refinement" 或 "Iterative array-domain cancellation"。

### 方向 E（备选，理论上最强但实现重）：DML / WSF 把 Route B 当初值

- **核心改动**：以 Route B 输出做初值，用 Newton / Gauss-Newton 解：

  `min_{θ_1, θ_2}  trace[(I - A(θ) · A(θ)^+) · R_ss]`

- **预期收益**：高 SNR 下逼近 CRLB；低 SNR 下不一定优于 Root-MUSIC，且对初值敏感（但 Route B 给的初值通常够用）。
- **论文表述**：「ML refinement of FBSS-Beamspace MUSIC」，分量重，但创新点足。

### 执行优先级

1. 方向 A 正式化为 Prototype 6（**本文第三部分给出完整执行指令**）
2. 方向 B 叠加到 Prototype 6 (proto6 跑通后再做)
3. 视效果再决定是否做方向 D / C / E

### 4.3 函数 F1：`doa_root_music_array.m`

#### 4.3.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_array(y, K, lambda, d, Lc)
% Array-domain Root-MUSIC after FBSS.
% 输入：
%   y       N x T_snap   阵元域快拍
%   K       FBSS 子阵长度 (与 Route B 保持一致, e.g. 56)
%   lambda  波长 (m)
%   d       阵元间距 (m, 与 Route B 保持一致, e.g. 0.047)
%   Lc      目标数 (=2)
% 输出：
%   doa_value   1 x Lc       两个 DOA 估计 (deg, 升序)；失败时返回 NaN
%   debug_info  struct       字段如下：
%       .eigvals             K x 1     Rss 特征值降序
%       .lambda2_over_noise  scalar    第 2 大特征值 / 噪声底均值 (Lc+1..Lc+min(K-Lc,6))
%       .num_inside_roots    scalar    单位圆内的根数
%       .root_distance_unit  Lc x 1    被选中根的 abs(|z|-1) 值 (越小越好)
```

#### 4.3.2 实现要点（参照 `proto5a_refined2` 第 851-900 行 `estimate_root_music_from_fbss_cov`）

```matlab
% 1) 阵元域协方差
T_snap = size(y, 2);
Rxx = (y * y') / T_snap;
Rxx = 0.5 * (Rxx + Rxx');

% 2) 阵元域 FBSS（直接调用 step_07_5_*/mssp_array_fb.m）
Rss = mssp_array_fb(Rxx, K);
Rss = 0.5 * (Rss + Rss');

% 3) 特征分解
[V, D] = eig(Rss);
eigvals = real(diag(D));
[eigvals, idx] = sort(eigvals, 'descend');
V = V(:, idx);

% 4) 噪声子空间投影矩阵
En = V(:, Lc+1:end);
C  = En * En';

% 5) 构造 Root-MUSIC 多项式系数 (沿对角线 C 求和)
M = K;
poly_coeffs = zeros(1, 2*M - 1);
lag_list = -(M-1):(M-1);
for ii = 1:numel(lag_list)
    poly_coeffs(ii) = sum(diag(C, lag_list(ii)));
end

% 6) 求根
rts = roots(fliplr(poly_coeffs));
inside_roots = rts(abs(rts) < 1);

% 7) 选距单位圆最近的 Lc 个根
if numel(inside_roots) < Lc
    doa_value = nan(1, Lc);
    return;
end
[~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
chosen = inside_roots(ord(1:Lc));

% 8) 角度反推 (steering 用 exp(-j*2*pi*d*n*sin(theta)/lambda))
omega = angle(chosen);
sin_theta = -(lambda / (2*pi*d)) * omega;
if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
    doa_value = nan(1, Lc);
    return;
end
sin_theta = min(max(real(sin_theta), -1), 1);
doa_value = sort(asind(sin_theta)).';
doa_value = doa_value(:).';

% 9) 诊断信息
noise_start = Lc + 1;
noise_end   = min(numel(eigvals), Lc + 6);
noise_floor = mean(eigvals(noise_start:noise_end));
debug_info.eigvals             = eigvals;
debug_info.lambda2_over_noise  = eigvals(2) / max(noise_floor, eps);
debug_info.num_inside_roots    = numel(inside_roots);
debug_info.root_distance_unit  = abs(abs(chosen) - 1);
```

#### 4.3.3 与现有 proto5a 实现的差异

- 现有 `estimate_root_music_from_fbss_cov(Rss, D, lambda, d)` 是接收 `Rss` 的版本；
- 新函数接收原始 `y`，内部完成 `Rxx → FBSS → Root-MUSIC`，方便论文图直接引用一个函数；
- 增加了 `debug_info`，便于后续诊断 `lambda2/noise_floor`。

### 4.4 函数 F2：`doa_root_music_beamspace.m`

#### 4.4.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace(y, K, Tk, lambda, d, Lc)
% Beamspace Root-MUSIC after FBSS + centerT projection.
% 输入：
%   y       N x T_snap   阵元域快拍
%   K       FBSS 子阵长度
%   Tk      K x M_b      centerT 投影矩阵 (与 Route B 一致, M_b = center_beam_count)
%   lambda, d, Lc        同 doa_root_music_array
% 输出：
%   doa_value   1 x Lc   两个 DOA 估计 (deg, 升序)；失败时返回 NaN
%   debug_info  struct   字段：

%       .lambda2_over_noise scalar
%       .num_inside_roots  scalar
%       .root_distance_unit Lc x 1
```

#### 4.4.2 实现要点

> 注意：`Tk` 是 QR 之后的近似酉矩阵，不是严格 Vandermonde。在 beamspace 域做 Root-MUSIC 需要先求出 `b(θ) = Tk' * a(θ)` 与 `θ` 的解析关系。这里采用「**对 `b(θ)^H E_n_b E_n_b^H b(θ)` 的多项式系数**」做法：

```matlab
% 1) 同 F1 步骤 1~2 得到 Rss (K x K)
T_snap = size(y, 2);
Rxx = (y * y') / T_snap;
Rxx = 0.5 * (Rxx + Rxx');
Rss = mssp_array_fb(Rxx, K);
Rss = 0.5 * (Rss + Rss');

% 2) 投影到 beamspace
%    注意：与 DOA_three_music_new_route_centerT.m 保持完全相同的投影方向
%    Tk 用 exp(+j ...), aK 用 exp(-j ...)，故 Rb = Tk.' * Rss * conj(Tk)
Rb = Tk.' * Rss * conj(Tk);
Rb = 0.5 * (Rb + Rb');

% 3) 特征分解
[Vb, Db] = eig(Rb);
eigvals_rb = real(diag(Db));
[eigvals_rb, idx] = sort(eigvals_rb, 'descend');
Vb = Vb(:, idx);
En_b = Vb(:, Lc+1:end);

% 4) 把 beamspace 噪声子空间映回阵元域
%    M(θ) = aK(θ)^H * conj(Tk) * En_b * En_b^H * Tk.' * aK(θ)
%        = aK(θ)^H * Q * aK(θ),  Q := conj(Tk) * (En_b En_b^H) * Tk.'
Q = conj(Tk) * (En_b * En_b') * Tk.';
Q = 0.5 * (Q + Q');                  % 数值对称化

% 5) 沿对角线求多项式系数 (复 Toeplitz 形式)
M = K;
poly_coeffs = zeros(1, 2*M - 1);
lag_list = -(M-1):(M-1);
for ii = 1:numel(lag_list)
    poly_coeffs(ii) = sum(diag(Q, lag_list(ii)));
end

% 6) 求根、选根、反推角度 (与 F1 步骤 6~8 完全一致)
rts = roots(fliplr(poly_coeffs));
inside_roots = rts(abs(rts) < 1);
if numel(inside_roots) < Lc
    doa_value = nan(1, Lc);
    return;
end
[~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
chosen = inside_roots(ord(1:Lc));

omega = angle(chosen);
sin_theta = -(lambda / (2*pi*d)) * omega;
if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
    doa_value = nan(1, Lc);
    return;
end
sin_theta = min(max(real(sin_theta), -1), 1);
doa_value = sort(asind(sin_theta)).';
doa_value = doa_value(:).';

% 7) 诊断
noise_start = Lc + 1;
noise_end   = min(numel(eigvals_rb), Lc + 6);
noise_floor = mean(eigvals_rb(noise_start:noise_end));
debug_info.eigvals_rb            = eigvals_rb;
debug_info.lambda2_over_noise    = eigvals_rb(2) / max(noise_floor, eps);
debug_info.num_inside_roots      = numel(inside_roots);
debug_info.root_distance_unit    = abs(abs(chosen) - 1);
```

> **实施提示**：`Q = conj(Tk) * En_b * En_b' * Tk.'` 仍然是 `K x K`，所以多项式仍然是 `2(K-1)` 阶。这是把 beamspace 噪声子空间「拉回」阵元域 ULA 流形后再做 Root-MUSIC，比直接在 `Rb` 上做更稳。如果之后想做严格 beamspace Root-MUSIC（在 `M_b` 阶多项式上），需要 `Tk` 严格满足某种 Vandermonde 性质，目前 QR 出来的 `Tk` 不满足，**先按本写法实现**。

### 6.3 函数 F1：`toeplitz_project.m`

#### 6.3.1 函数签名

```matlab
function R_t = toeplitz_project(R)
% Hermitian Toeplitz projection.
%
% 在 Hermitian 矩阵 R 上做沿对角线平均，强制其满足 Toeplitz 结构。
% 适用于 ULA + 时间平稳假设下的协方差矩阵：真协方差严格 Toeplitz，
% 有限快拍 / FBSS 残留的非 Toeplitz 分量来自噪声扰动，强制 Toeplitz
% 化等于做一次免费平均。
%
% 输入：
%   R   K x K   Hermitian 矩阵 (典型为 FBSS 后的 Rss 或 beamspace Rb)
% 输出：
%   R_t K x K   Hermitian Toeplitz 矩阵
```

#### 6.3.2 完整实现

```matlab
function R_t = toeplitz_project(R)
    K = size(R, 1);
    if size(R, 2) ~= K
        error('toeplitz_project: R must be square.');
    end

    % 1) 数值厄米化 (保险)
    R = 0.5 * (R + R');

    % 2) 沿各上对角线求均值
    %    diag(R, k) 与 diag(R, -k) 互为共轭，所以只需要算 k = 0..K-1
    r = zeros(K, 1);
    for k = 0:K-1
        r(k+1) = mean(diag(R, k));
    end

    % 3) 对角线必须是实数 (Hermitian 矩阵的对角线一定实)
    r(1) = real(r(1));

    % 4) toeplitz(c) 在 MATLAB 中等价于 toeplitz(c, conj(c)),
    %    自动产生 Hermitian Toeplitz 矩阵
    R_t = toeplitz(r);

    % 5) 数值厄米化 (再次保险)
    R_t = 0.5 * (R_t + R_t');
end
```

#### 6.3.3 实施提示

- `toeplitz(r)` 在 MATLAB 中传入复数列向量时，会自动用 `conj(r)` 作为第一行，产生 Hermitian Toeplitz 矩阵；
- 步骤 3 强制 `r(1)` 实数化是为了消除浮点误差，不是算法本身要求；
- 不要试图用 `for` 循环手动填矩阵 —— 直接 `toeplitz(r)` 比 `for` 快几十倍，且没有越界风险；
- 这个函数同样可以作用在 `Rb` (beamspace) 上，但 **beamspace 投影后协方差严格意义上不是 Toeplitz**（因为 `Tk' * (Toeplitz Rss) * conj(Tk)` 一般不再是 Toeplitz）。所以在 beamspace 版本里，正确做法是 **先对 Rss 做 Toeplitz 投影，再投影到 beamspace**，而不是反过来。proto7 的两个函数 F2 / F3 都遵循这个顺序。

### 6.4 函数 F2：`doa_root_music_array_toeplitz.m`

#### 6.4.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_array_toeplitz(y, K, lambda, d, Lc)
% Array-domain Root-MUSIC after FBSS + Toeplitz projection.
%
% 与 doa_root_music_array.m 完全相同，除了在 FBSS 后插入一次 Toeplitz 投影。
%
% 输入 / 输出：与 doa_root_music_array.m 一致，debug_info 额外增加：
%   .lambda2_over_noise_before_tp  (Toeplitz 投影前)
%   .lambda2_over_noise_after_tp   (= debug_info.lambda2_over_noise, Toeplitz 投影后)
%   .toeplitz_residual_norm        (Rss - toeplitz_project(Rss) 的 Frobenius 范数 / Rss 范数)
```

#### 6.4.2 完整实现

```matlab
function [doa_value, debug_info] = doa_root_music_array_toeplitz(y, K, lambda, d, Lc)
    % 1) 阵元域协方差
    T_snap = size(y, 2);
    Rxx = (y * y') / T_snap;
    Rxx = 0.5 * (Rxx + Rxx');

    % 2) 阵元域 FBSS (复用 step_07_5_*/mssp_array_fb.m)
    Rss_pre = mssp_array_fb(Rxx, K);
    Rss_pre = 0.5 * (Rss_pre + Rss_pre');

    % 2.5) Toeplitz 投影 (proto7 的唯一新增步骤)
    Rss = toeplitz_project(Rss_pre);

    % 3~9) 与 doa_root_music_array.m 完全一致
    [V, D] = eig(Rss);
    eigvals = real(diag(D));
    [eigvals, idx] = sort(eigvals, 'descend');
    V = V(:, idx);

    En = V(:, Lc+1:end);
    C  = En * En';

    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(C, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed(Rss_pre, Rss, eigvals, Lc);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed(Rss_pre, Rss, eigvals, Lc);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 9) 诊断信息：同时记录 Toeplitz 投影前后的 lambda2/noise
    debug_info = fill_debug_info(Rss_pre, Rss, eigvals, Lc, chosen);
end

function debug_info = fill_debug_info(Rss_pre, Rss_post, eigvals_post, Lc, chosen)
    [~, D_pre] = eig(0.5 * (Rss_pre + Rss_pre'));
    eigvals_pre = sort(real(diag(D_pre)), 'descend');

    debug_info.eigvals                   = eigvals_post;
    debug_info.eigvals_pre_tp            = eigvals_pre;
    debug_info.lambda2_over_noise        = compute_lambda2_over_noise(eigvals_post, Lc);
    debug_info.lambda2_over_noise_before_tp = compute_lambda2_over_noise(eigvals_pre, Lc);
    debug_info.lambda2_over_noise_after_tp  = debug_info.lambda2_over_noise;
    debug_info.num_inside_roots          = numel(chosen);
    debug_info.root_distance_unit        = abs(abs(chosen) - 1);
    debug_info.toeplitz_residual_norm    = norm(Rss_pre - Rss_post, 'fro') / max(norm(Rss_pre, 'fro'), eps);
end

function debug_info = fill_debug_failed(Rss_pre, Rss_post, eigvals_post, Lc)
    debug_info = fill_debug_info(Rss_pre, Rss_post, eigvals_post, Lc, []);
    debug_info.root_distance_unit = nan(Lc, 1);
end

function r = compute_lambda2_over_noise(eigvals, Lc)
    if numel(eigvals) < Lc + 1
        r = NaN;
        return;
    end
    noise_start = Lc + 1;
    noise_end   = min(numel(eigvals), Lc + 6);
    noise_floor = mean(eigvals(noise_start:noise_end));
    r = eigvals(2) / max(noise_floor, eps);
end
```

### 6.5 函数 F3：`doa_root_music_beamspace_toeplitz.m`

#### 6.5.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace_toeplitz(y, K, Tk, lambda, d, Lc)
% Beamspace Root-MUSIC after FBSS + Toeplitz projection + centerT projection.
%
% 与 doa_root_music_beamspace.m 完全相同，除了在 FBSS 后、centerT 投影前
% 插入一次 Toeplitz 投影。
%
% 注意：Toeplitz 投影必须发生在 Rss 上（阵元域）而非 Rb 上（beamspace 域），
% 因为 Rb = Tk' * Rss * conj(Tk) 一般不是 Toeplitz，对 Rb 做 Toeplitz 投影
% 既无理论依据，又会破坏其物理含义。
%
% 输入 / 输出：与 doa_root_music_beamspace.m 一致，debug_info 额外字段同 F2。
```

#### 6.5.2 完整实现

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace_toeplitz(y, K, Tk, lambda, d, Lc)
    % 1) 阵元域协方差
    T_snap = size(y, 2);
    Rxx = (y * y') / T_snap;
    Rxx = 0.5 * (Rxx + Rxx');

    % 2) 阵元域 FBSS
    Rss_pre = mssp_array_fb(Rxx, K);
    Rss_pre = 0.5 * (Rss_pre + Rss_pre');

    % 2.5) Toeplitz 投影 (proto7 唯一新增步骤，必须在 Rss 上做，不是 Rb)
    Rss = toeplitz_project(Rss_pre);

    % 3) 投影到 beamspace (与 doa_root_music_beamspace.m 一致)
    Rb = Tk.' * Rss * conj(Tk);
    Rb = 0.5 * (Rb + Rb');

    % 4) 特征分解
    [Vb, Db] = eig(Rb);
    eigvals_rb = real(diag(Db));
    [eigvals_rb, idx] = sort(eigvals_rb, 'descend');
    Vb = Vb(:, idx);
    En_b = Vb(:, Lc+1:end);

    % 5) 把 beamspace 噪声子空间映回阵元域
    Q = conj(Tk) * (En_b * En_b') * Tk.';
    Q = 0.5 * (Q + Q');

    % 6) 求根、选根、反推角度 (与 doa_root_music_beamspace.m 完全一致)
    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(Q, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rss_pre, Rss, eigvals_rb, Lc);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rss_pre, Rss, eigvals_rb, Lc);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 7) 诊断
    debug_info = fill_debug_info_bs(Rss_pre, Rss, eigvals_rb, Lc, chosen);
end

function debug_info = fill_debug_info_bs(Rss_pre, Rss_post, eigvals_rb, Lc, chosen)
    [~, D_pre] = eig(0.5 * (Rss_pre + Rss_pre'));
    eigvals_rss_pre  = sort(real(diag(D_pre)), 'descend');
    [~, D_post] = eig(0.5 * (Rss_post + Rss_post'));
    eigvals_rss_post = sort(real(diag(D_post)), 'descend');

    debug_info.eigvals_rb                = eigvals_rb;
    debug_info.eigvals_rss_pre_tp        = eigvals_rss_pre;
    debug_info.eigvals_rss_after_tp      = eigvals_rss_post;
    debug_info.lambda2_over_noise        = compute_lambda2_over_noise(eigvals_rb, Lc);
    debug_info.lambda2_over_noise_before_tp = compute_lambda2_over_noise(eigvals_rss_pre, Lc);
    debug_info.lambda2_over_noise_after_tp  = compute_lambda2_over_noise(eigvals_rss_post, Lc);
    debug_info.num_inside_roots          = numel(chosen);
    debug_info.root_distance_unit        = abs(abs(chosen) - 1);
    debug_info.toeplitz_residual_norm    = norm(Rss_pre - Rss_post, 'fro') / max(norm(Rss_pre, 'fro'), eps);
end

function debug_info = fill_debug_failed_bs(Rss_pre, Rss_post, eigvals_rb, Lc)
    debug_info = fill_debug_info_bs(Rss_pre, Rss_post, eigvals_rb, Lc, []);
    debug_info.root_distance_unit = nan(Lc, 1);
end
```

### 6.10 执行后结果总览 + 失败根因分析（论文反面教材源材料）

#### 6.10.1 实测 SNR90

- `tol_success_rate ≈ 0`（但每次都输出错）

#### 6.10.2 典型样本对照

`bw/7, snr = 18 dB` 单样本：

- 真值：`[12.8, 13.2]`（间隔 0.4°，中心 13.0°）
- `proto6_array` 估：`[12.7653, 13.1166]`
- `proto7_array` 估：`[12.9076, 13.0166]` ← **明显被向中心 13.0° 拉拢，间隔被压缩**

同样本的诊断量：

- `lambda2_over_noise_after_tp = 8.9531` ← 看似变好（提升约 3 倍）
- `toeplitz_residual_norm = 0.0093` ← Toeplitz 残差很小

#### 6.10.3 失败根因 — 相干源与 Toeplitz 假设的不兼容

第 4.5.1 节里写的「ULA + 时间平稳假设下，真协方差严格 Toeplitz」**仅在非相干源下成立**。

相干等幅双目标的真协方差展开为：

```
R_xx_true = E[y_clean · y_clean^H] = (a_a + a_b)(a_a + a_b)^H
         = a_a · a_a^H  +  a_b · a_b^H  +  a_a · a_b^H  +  a_b · a_a^H
                                          ───────────────────────────
                                          此两项是「交叉相位项」
```

- 只有 `a_a · a_a^H` 和 `a_b · a_b^H` 是 Hermitian Toeplitz；
- 交叉项 `a_a · a_b^H` 的第 `(i,j)` 元素为 `exp(-j(i-1)·μ_a) · exp(j(j-1)·μ_b)`，**它同时依赖 `i+j` 而不仅依赖 `i-j`，因此不满足 Toeplitz 结构**。

FBSS 把秩 1 提升到秩 2，但并不消除交叉项，所以 `Rss` 仍带 `(μ_a, μ_b)` 的相位差结构 —— 这正是 Root-MUSIC 找到两个目标的**关键信息**。

`toeplitz_project` 沿对角线取均值：

```
[Toeplitz(R)](i,j) = mean_{k-l = i-j} R(k, l)
```

它把交叉相位项的 `i+j` 依赖部分平均消去，等价于**把两目标的相位中心强行合并到 `(μ_a + μ_b)/2`**。Root-MUSIC 在新协方差上求出的两个根因此被拖向该中心，这就是 6.10.2 中 `[12.9076, 13.0166]` 被向 `13.0` 拉拢的直接来源。

#### 6.10.4 为什么 lambda2/noise 反而变好

Toeplitz 投影确实是个**有效的噪声平均器** —— 它把非对角元素的噪声起伏平掉，所以 `lambda2/noise` 从 `2.87` 翻到 `8.95`。但**信号子空间的"长度"变得很干净，"方向"却被指向了错误的位置**。

这正好印证了 `raw ≈ 1` / `tol ≈ 0` 的组合：算法稳定地输出两个有限角，但每次都输出错。**诊断量与最终性能脱节**，这一现象本身也是值得写进论文的方法论提醒。

#### 6.10.5 论文反面教材段落（可直接引用）

> 为进一步降低有限快拍下子空间扰动方差，本文尝试在 FBSS 协方差 `R_ss` 上叠加 Hermitian Toeplitz 投影。然而实验表明，尽管 Toeplitz 投影显著提升了 `R_ss` 的特征值分离比（`λ_2/λ_n` 从 `2.87` 提升至 `8.95`），但其在相干等幅双目标场景下系统性地将 Root-MUSIC 估计的两个根拖向 `(μ_a + μ_b)/2`，导致目标角度被压缩，`tol_success_rate` 反而降至 `0`。
>
> 根因分析表明，相干源的真协方差 `R_xx_true = (a_a + a_b)(a_a + a_b)^H` 含有交叉相位项 `a_a · a_b^H`，该项不满足 Hermitian Toeplitz 结构（其第 `(i,j)` 元素同时依赖 `i+j` 而非仅依赖 `i-j`）。强制 Toeplitz 化会将交叉项的 `i+j` 依赖部分平均消去，等价于将两个目标的相位中心强行合并。这一现象揭示了 Toeplitz 投影理论对源信号统计独立性假设的强依赖性，在相干源场景下不可直接套用。

#### 6.10.6 处置决定

- **proto7 留在主目录**与 proto6 配对（不归档到 `archive_failed_prototypes/`），因为它的失败结论有深度物理解释，论文里要被具体引用。
- **不再尝试 Toeplitz on `R_xx`、Toeplitz on `R_b`、Toeplitz with weighted averaging 等任何变体** —— 它们都撞同一面墙。
- proto7 不作为正式创新点，但 **6.10.5 的反面教材段落**作为论文「算法选型与失败方向」章节的源材料使用。

### 7.9 SNR90 离散抖动说明（首跑后追加，2026-05-20）

#### 7.9.1 现象

2026-05-20 首跑 fullscan 实测：

- baseline 10 档 SNR90 = `[-4, -4, -2, 4, 8, 12, 16, 18, 22, 24]`（与第 7.5 步 fullscan 完全一致）
- proto6 10 档 SNR90 = `[-4, -4, -2, 4, 8, 12, 14, 16, 18, 22]`
- **proto6 短扫记录值 (bw/7~bw/10) = `[14, 16, 20, 22]`**
- **proto6 fullscan 实测值 (bw/7~bw/10) = `[14, 16, 18, 22]`** ← bw/9 抖了 1 档

#### 7.9.2 抖动是 Monte Carlo 离散指标的固有特性

SNR90 由「`tol_success_rate` 在离散 `snr_list` 上首次 ≥ 0.9」定义，本质是把连续概率函数离散化到 2 dB 网格。在 `Metkl = 200` 下：

- `tol_rate` 估计的 95% 置信区间半宽 ≈ `1.96 × √(0.5 × 0.5 / 200) ≈ ±0.07`
- 任一 SNR 点的 `tol_rate` 真实值在 `[实测 - 0.07, 实测 + 0.07]` 范围内
- 临界点（短扫 bw/9 @ 20 dB 实测 `0.815`）的 95% 置信区间 = `[0.745, 0.885]`，**离 0.90 门槛只差 0.085**
- 因此在不同 base_seed 下，bw/9 的 SNR90 可能在 18 / 20 / 22 dB 之间抖动 ±1 档

#### 7.9.3 为什么 bw/9 上侧抖动反而是好结果

bw/9 从 20 dB 抖到 18 dB，说明 proto6 的真实 SNR90 在 `[18, 20]` 之间，**proto6 相对 baseline 的真实优势在 bw/9 这一档实际上是 3~4 dB，而不是短扫显示的 2 dB**。这对论文主结论是加强，不是削弱。

#### 7.9.4 论文里怎么写

在论文「实验结果」章节描述 fullscan 时，建议这样表述：

> "受 Monte Carlo 离散指标固有抖动影响，proto6 在 bw/9 上的 SNR90 在 18~20 dB 之间随 seed 微抖。即便取保守值 20 dB，proto6 相对 baseline 仍保持 2 dB 的稳定优势；取实测值 18 dB，则优势进一步扩大到 4 dB。整体 SNR90 曲线（图 X）清晰显示 proto6 在 bw/3~bw/10 各档均不劣于 baseline，且在 bw/3 起持续 1~2 档分辨增益。"

#### 7.9.5 何时该真的停下排查

只有在以下情况才需要 debug，而不是把抖动当 bug：

- baseline 的 10 档 SNR90 任一档与第 7.5 步不一致（公平性回归断裂，必停）
- proto6 的某一档严格 **>** baseline 同档（这违反 "Root-MUSIC 替换 grid-MUSIC 不可能更差" 的理论，必停）
- proto6 曲线非单调，出现间隔变小但 SNR90 变低的反常（必停）
- proto6 fullscan 抖动幅度 > 1 档（例如从 20 dB 抖到 14 dB 或 24 dB，超过抽样波动可解释范围，必停）

bw/9 单档上侧抖动属于以上 4 类之外，**放行**。

### 8.3 酉变换矩阵 Q 的构造（核心理论）

#### 8.3.1 理论简介

对 K × K Hermitian Toeplitz 矩阵 R（或更一般的 persymmetric Hermitian 矩阵，即满足 `J·R*·J = R`），存在酉矩阵 Q (Lee 1981) 使得：

```
R_real = Q^H · R · Q
```

是 K × K **实对称矩阵**。这里 J 是 K × K 反对角矩阵 (`anti-identity`)，`*` 是复共轭。

**关键性质**：

- `Q^H · Q = I_K`（酉性）
- 若 R 满足 persymmetric Hermitian，则 R_real 是实对称
- R 与 R_real 有相同的特征值，**且**特征向量满足 `v_real = Q^H · v_complex`
- **实数 eig 的数值稳定性优于复数 eig**，尤其在 `cond(R) > 1e6` 的小快拍场景

#### 8.3.2 persymmetric 来源

我们的 `Rss` 经过 FBSS 之后**严格 persymmetric Hermitian**（FB 平均的副产品）；
我们的 `Rb = Tk' · Rss · conj(Tk)` **不严格 persymmetric**，因为 centerT 投影 `Tk` 不一定满足 `J·conj(Tk) = Tk·P` 这样的对称性。所以 beamspace 版本里需要**额外做一次 beamspace 域 FB 平均**：

```
Rb_fb = 0.5 · (Rb + J_b · Rb* · J_b)
```

其中 `J_b` 是 M_b × M_b 反对角矩阵。这一步保证 Rb_fb 是 persymmetric，从而酉变换后实数化成立。

#### 8.3.3 Q 的显式构造

**K 偶数情况** (K = 2m)：

```
Q = (1/√2) · [ I_m    j·I_m
              J_m   -j·J_m ]
```

**K 奇数情况** (K = 2m+1，中心需特殊处理)：

```
Q = (1/√2) · [ I_m       0      j·I_m
              0^T       √2      0^T
              J_m       0     -j·J_m ]
```

其中 `0` 是 m × 1 零向量。

### 8.4 函数 F1：`unitary_matrix.m`

#### 8.4.1 函数签名

```matlab
function Q = unitary_matrix(K)
% Constructs K x K unitary matrix Q (Lee 1981) that maps persymmetric
% Hermitian complex matrices to real symmetric matrices via
%   R_real = Q' * R * Q
%
% K can be even or odd.
%
% 输入：
%   K   正整数 (matrix size)
% 输出：
%   Q   K x K complex unitary matrix
```

#### 8.4.2 完整实现

```matlab
function Q = unitary_matrix(K)
    if K < 1 || mod(K, 1) ~= 0
        error('unitary_matrix: K must be a positive integer.');
    end

    if mod(K, 2) == 0
        % 偶数情况
        m = K / 2;
        Im = eye(m);
        Jm = fliplr(eye(m));
        Q = (1/sqrt(2)) * [Im,        1j*Im;
                           Jm,       -1j*Jm];
    else
        % 奇数情况
        m = (K - 1) / 2;
        Im = eye(m);
        Jm = fliplr(eye(m));
        zero_col = zeros(m, 1);
        zero_row = zeros(1, m);
        Q = (1/sqrt(2)) * [Im,       zero_col,   1j*Im;
                           zero_row, sqrt(2),    zero_row;
                           Jm,       zero_col,  -1j*Jm];
    end
end
```

#### 8.4.3 自检验证（强烈建议在实现完后跑一次）

```matlab
% 自检 1：酉性
K = 56;
Q = unitary_matrix(K);
err_unitary = norm(Q' * Q - eye(K), 'fro');
assert(err_unitary < 1e-12, 'Q 不是酉矩阵');

% 自检 2：对 persymmetric Hermitian 输入产生实对称输出
R = randn(K) + 1j*randn(K);
R = R * R';                    % Hermitian
R = 0.5 * (R + fliplr(eye(K)) * conj(R) * fliplr(eye(K)));   % FB 平均使其 persymmetric
R_real = Q' * R * Q;
err_imag = norm(imag(R_real), 'fro') / norm(R_real, 'fro');
assert(err_imag < 1e-10, sprintf('R_real 不是实矩阵, err_imag = %.2e', err_imag));

err_sym = norm(real(R_real) - real(R_real).', 'fro') / norm(real(R_real), 'fro');
assert(err_sym < 1e-10, 'R_real 不是对称');
fprintf('unitary_matrix self-check passed for K=%d\n', K);
```

如果自检失败，绝不要继续往下做 —— 一定是 Q 的构造写错了。

### 8.5 函数 F2：`doa_root_music_unitary_array.m`

#### 8.5.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_unitary_array(y, K, lambda, d, Lc)
% Unitary Array-domain Root-MUSIC after FBSS.
%
% 与 doa_root_music_array.m 完全相同，除了在特征分解阶段使用酉变换 + 实对称 eig。

% 输入 / 输出：与 doa_root_music_array.m 一致，debug_info 额外字段：
%   .cond_number_complex     原 Rss 的条件数
%   .cond_number_real        Rss_real 的条件数
%   .max_imag_part_rel       R_real 残余虚部 / 实部范数（应 < 1e-10）
```

#### 8.5.2 完整实现

```matlab
function [doa_value, debug_info] = doa_root_music_unitary_array(y, K, lambda, d, Lc)
    % 1) 阵元域协方差
    T_snap = size(y, 2);
    Rxx = (y * y') / T_snap;
    Rxx = 0.5 * (Rxx + Rxx');

    % 2) 阵元域 FBSS (调用 step_07_5_*/mssp_array_fb.m)
    Rss = mssp_array_fb(Rxx, K);
    Rss = 0.5 * (Rss + Rss');

    % 3) 酉变换实数化（proto8 的唯一新增步骤）
    Q = unitary_matrix(K);
    Rss_real_complex = Q' * Rss * Q;

    % 记录残余虚部用于诊断
    norm_full = norm(Rss_real_complex, 'fro');
    max_imag_part_rel = norm(imag(Rss_real_complex), 'fro') / max(norm_full, eps);

    % 强制取实部消除浮点虚部
    Rss_real = real(Rss_real_complex);
    Rss_real = 0.5 * (Rss_real + Rss_real');     % 强制对称

    % 4) 实对称特征分解
    [V_real, D_real] = eig(Rss_real);
    eigvals = real(diag(D_real));
    [eigvals, idx] = sort(eigvals, 'descend');
    V_real = V_real(:, idx);

    if numel(eigvals) <= Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_arr(Rss, Rss_real, eigvals, Lc, max_imag_part_rel);
        return;
    end

    En_real = V_real(:, Lc+1:end);

    % 5) 把实数噪声子空间变回复数域
    En = Q * En_real;
    C = En * En';
    C = 0.5 * (C + C');

    % 6) Root-MUSIC 求根（与 doa_root_music_array.m 完全一致）
    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(C, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_arr(Rss, Rss_real, eigvals, Lc, max_imag_part_rel);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_arr(Rss, Rss_real, eigvals, Lc, max_imag_part_rel);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 7) 诊断信息
    debug_info = fill_debug_info_arr(Rss, Rss_real, eigvals, Lc, chosen, max_imag_part_rel);
end

function debug_info = fill_debug_info_arr(Rss, Rss_real, eigvals, Lc, chosen, max_imag_part_rel)
    noise_start = Lc + 1;
    noise_end   = min(numel(eigvals), Lc + 6);
    noise_floor = mean(eigvals(noise_start:noise_end));

    debug_info.eigvals             = eigvals;
    debug_info.lambda2_over_noise  = eigvals(2) / max(noise_floor, eps);
    debug_info.num_inside_roots    = numel(chosen);
    debug_info.root_distance_unit  = abs(abs(chosen) - 1);
    debug_info.cond_number_complex = cond(Rss);
    debug_info.cond_number_real    = cond(Rss_real);
    debug_info.max_imag_part_rel   = max_imag_part_rel;
end

function debug_info = fill_debug_failed_arr(Rss, Rss_real, eigvals, Lc, max_imag_part_rel)
    debug_info = fill_debug_info_arr(Rss, Rss_real, eigvals, Lc, [], max_imag_part_rel);
    debug_info.root_distance_unit  = nan(Lc, 1);
end
```

#### 8.5.3 关键实施提示

- **`max_imag_part_rel` 必须 < 1e-10**。如果不是，说明 Rss 没有严格 persymmetric（FBSS 出问题）或 Q 构造错误，**必须停下排查**，不要简单 `real()` 掉。
- 步骤 5 `En = Q * En_real` 是核心：实数噪声子空间映回复数域后才能做 Root-MUSIC 多项式（因为 Root-MUSIC 的多项式系数本质是复数）。
- `cond(Rss)` 和 `cond(Rss_real)` 应该**接近相同**（理论上酉变换不改变条件数）。如果差异 > 1%，是数值误差，可接受；如果差异 > 10%，说明 Q 不是严格酉，要排查。

```matlab
    M_b = size(Rb, 1);
    J_b = fliplr(eye(M_b));
    Rb_fb = 0.5 * (Rb + J_b * conj(Rb) * J_b);
    Rb_fb = 0.5 * (Rb_fb + Rb_fb');

    % 4) 酉变换实数化
    Q_b = unitary_matrix(M_b);
    Rb_real_complex = Q_b' * Rb_fb * Q_b;
    max_imag_part_rel = norm(imag(Rb_real_complex), 'fro') / max(norm(Rb_real_complex, 'fro'), eps);
    Rb_real = real(Rb_real_complex);
    Rb_real = 0.5 * (Rb_real + Rb_real');

    % 5) 实对称特征分解
    [Vb_real, Db] = eig(Rb_real);
    eigvals_rb = real(diag(Db));
    [eigvals_rb, idx] = sort(eigvals_rb, 'descend');
    Vb_real = Vb_real(:, idx);

    if numel(eigvals_rb) <= Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rb, Rb_real, eigvals_rb, Lc, max_imag_part_rel);
        return;
    end

    En_b_real = Vb_real(:, Lc+1:end);

    % 6) 映回复数域 beamspace，再拉回阵元域
    En_b = Q_b * En_b_real;
    Q = conj(Tk) * (En_b * En_b') * Tk.';
    Q = 0.5 * (Q + Q');

    % 7) Root-MUSIC (同 doa_root_music_beamspace.m)
    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(Q, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rb, Rb_real, eigvals_rb, Lc, max_imag_part_rel);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rb, Rb_real, eigvals_rb, Lc, max_imag_part_rel);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 8) 诊断
    debug_info = fill_debug_info_bs(Rb, Rb_real, eigvals_rb, Lc, chosen, max_imag_part_rel);
end

function debug_info = fill_debug_info_bs(Rb, Rb_real, eigvals_rb, Lc, chosen, max_imag_part_rel)
    noise_start = Lc + 1;
    noise_end   = min(numel(eigvals_rb), Lc + 6);
    noise_floor = mean(eigvals_rb(noise_start:noise_end));

    debug_info.eigvals_rb             = eigvals_rb;
    debug_info.lambda2_over_noise     = eigvals_rb(2) / max(noise_floor, eps);
    debug_info.num_inside_roots       = numel(chosen);
```

### 9.1 目标

把 RELAX (Li & Stoica, 1996) 的"估计 → 对消 → 重估计"迭代思路从 **FFT 域**搬到 **稳定子空间域**（即 Route B 的 FBSS + Root-MUSIC 子空间）：

1. 用 `proto6_array_root_music` 输出 `(θ_1^(0), θ_2^(0))` 作为初值；
2. 固定 `θ_2`，在阵元域 `y` 上对消该目标分量得到 `y_residual`；
3. 在 `y_residual` 上重做 FBSS + Root-MUSIC（取 `Lc=1` 单目标），更新 `θ_1`；
4. 角色互换，对消 `θ_1` 更新 `θ_2`；
5. 外层迭代到收敛。

### 9.1.1 与历史失败原型的关键区别（论文里要写这张表）

| 原型 | 对消域 | 初值来源 | 是否破坏 FBSS 解相干前提 | 实际结果 |
|---|---|---|---|---|
| proto3 | beamspace 协方差 Rb（秩 1 强对消） | proto4 局部 MUSIC | **是**（破坏双目标共享结构） | bw/8-10 全部 tol_rate=0，严重失败 |
| proto5a refined2 | FFT 域 Dirichlet 残差 | FFT 主峰 + 残差次峰 | 否（但 FFT 残差里次峰不可见） | tol_rate 偶有非零，但远不及 Root-MUSIC reference |
| proto7 | FBSS 后 Toeplitz 投影 | 不涉及对消 | 是（相干源不满足 Toeplitz） | 双目标被拖向中心，tol_rate≈0 |
| **proto9** | **阵元域快拍 `y`，联合 LS 估计幅度** | **proto6 Root-MUSIC（稳定）** | **否**（FBSS 仍完整作用于残差） | **预期 1~2 档 SNR90 改善** |

**proto9 的关键设计点**：

1. **对消在阵元域做**，不在 FBSS 后或 FFT 域 —— 保证 FBSS 仍能完整解相干；

4. **联合 LS 估计复幅度**，不假设源相干等幅 —— 算法不能依赖"我知道源是相干"。

### 9.3 算法核心数学（论文里要推导一遍）

#### 9.3.1 阵元域信号模型

```
y(:, t) = a(θ_1) · s_1(t) + a(θ_2) · s_2(t) + n(:, t),    t = 1, ..., T_snap
```

其中 `a(θ) = exp(-j · 2π · d/λ · (0:N-1)' · sin(θ))`。

#### 9.3.2 已知 `(θ_1, θ_2)` 时的复幅度联合 LS 估计

构造 manifold 矩阵 `A = [a(θ_1), a(θ_2)]`（N × 2 复矩阵），则对每个 `t`：

```
[β_1(t); β_2(t)] = A^+ · y(:, t)
```

其中 `A^+ = (A^H A)^(-1) A^H`（Moore-Penrose 伪逆）。

#### 9.3.3 对消目标 `target_idx` 后的残差快拍

记 `other_idx = 3 - target_idx`（双目标场景下另一目标的索引），则：

```
y_cancel(:, t) = a(θ_{other}) · β_{other}(t)
y_residual(:, t) = y(:, t) - y_cancel(:, t)
```

矩阵化（更高效）：

```
cancel_matrix = a(θ_{other}) · (A^+)_{other_row, :}    (N × N)
y_residual = y - cancel_matrix · y
```

注意 `cancel_matrix` 是秩 1 矩阵（`a(θ_{other})` 列向量 × `(A^+)_{other_row, :}` 行向量），所以这个表达**等价于先估计每个 `t` 的 `β_{other}(t)` 然后逐 `t` 对消**，但用矩阵乘法一次完成。

#### 9.3.4 外层迭代

```
对 outer = 1, 2, ..., max_outer_iter:
    保存 theta_prev = theta_est
    对 target_idx = 1, 2:
        计算 y_residual (对消 other_idx 目标)
        在 y_residual 上做 FBSS + Root-MUSIC 取 Lc=1 单目标
        更新 theta_est(target_idx) ← 新结果
    若 max(|theta_est - theta_prev|) < angle_tol_stop_deg：收敛，break
```

#### 9.3.5 最小间隔 guard

为防止两目标在迭代中坍缩到一起（这是 RELAX 类算法的常见失败模式），加入：

```
if (theta_est(2) - theta_est(1)) < min_sep_guard:
    theta_mid = mean(theta_est)
    theta_est = [theta_mid - min_sep_guard/2, theta_mid + min_sep_guard/2]
```

推荐 `min_sep_guard = 0.05 deg`（约 1/10 个 bw/10 间隔）。

```matlab
function [doa_value, debug_info] = doa_subspace_relax_root_music( ...
    y, K, lambda, d, Lc, init_theta, max_outer_iter, angle_tol_stop_deg, min_sep_guard)

    % 默认参数
    if nargin < 5 || isempty(Lc),                  Lc = 2;                end
    if nargin < 6 || isempty(init_theta),          init_theta = [];       end
    if nargin < 7 || isempty(max_outer_iter),      max_outer_iter = 6;    end
    if nargin < 8 || isempty(angle_tol_stop_deg),  angle_tol_stop_deg = 1e-3; end
    if nargin < 9 || isempty(min_sep_guard),       min_sep_guard = 0.05;  end

    if Lc ~= 2
        error('doa_subspace_relax_root_music: 本实现仅支持 Lc=2 (双目标场景)。');
    end

    [N, ~] = size(y);

    % 默认初值：proto6_array
    if isempty(init_theta)
        init_theta = doa_root_music_array(y, K, lambda, d, Lc);
    end
    init_theta = sort(init_theta(:).');

    % 初值失败安全出口
    if any(~isfinite(init_theta)) || numel(init_theta) ~= Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_init_failed(init_theta, Lc);
        return;
    end

    theta_est = init_theta;
    theta_trace = nan(max_outer_iter, Lc);
    angle_update_trace = nan(max_outer_iter, 1);
    guard_applied_any = false;

    posN = (0:N-1).';

    for outer = 1:max_outer_iter
        theta_prev = theta_est;

        for target_idx = 1:Lc
            other_idx = 3 - target_idx;

            % 构造当前 manifold A = [a(θ_1), a(θ_2)]
            A = zeros(N, Lc);
            for kk = 1:Lc
                A(:, kk) = exp(-1j * 2*pi * posN * d * sind(theta_est(kk)) / lambda);
            end

            % 联合 LS 估计 β
            if rank(A) < Lc
                % manifold 共线（不应该发生在双目标分离场景）
                continue;
            end
            pinvA = pinv(A);

            % 构造对消矩阵：cancel_matrix = a(θ_other) · pinvA(other_idx, :)
            cancel_matrix = A(:, other_idx) * pinvA(other_idx, :);

            % 阵元域对消
            y_residual = y - cancel_matrix * y;

            % 在 y_residual 上做 Root-MUSIC 取 Lc=1 单目标
            [theta_single, ~] = doa_root_music_array(y_residual, K, lambda, d, 1);

            if isfinite(theta_single(1))
                theta_est(target_idx) = theta_single(1);
            end
        end

        % 排序 + 最小间隔 guard
        theta_est = sort(theta_est);
        if (theta_est(2) - theta_est(1)) < min_sep_guard
            theta_mid = mean(theta_est);
            theta_est = [theta_mid - min_sep_guard/2, theta_mid + min_sep_guard/2];
            guard_applied_any = true;
        end

        theta_trace(outer, :) = theta_est;
        angle_update_trace(outer) = max(abs(theta_est - theta_prev));

        % 收敛判定
        if angle_update_trace(outer) < angle_tol_stop_deg
            break;
        end
    end

    outer_iter_used = outer;

    % 最终残差功率（用最后一轮的 y_residual 平均功率）
    A_final = zeros(N, Lc);
    for kk = 1:Lc
        A_final(:, kk) = exp(-1j * 2*pi * posN * d * sind(theta_est(kk)) / lambda);
    end
    pinvA_final = pinv(A_final);
    cancel_matrix_final = A_final * pinvA_final;
    y_total_cancel = cancel_matrix_final * y;
    y_full_residual = y - y_total_cancel;
    final_residual_power = mean(abs(y_full_residual(:)).^2);

    doa_value = theta_est;
    debug_info.outer_iter_used        = outer_iter_used;
    debug_info.theta_trace            = theta_trace(1:outer_iter_used, :);
    debug_info.angle_update_trace     = angle_update_trace(1:outer_iter_used);
    debug_info.init_theta             = init_theta;
    debug_info.init_failed            = false;
    debug_info.guard_applied          = guard_applied_any;
    debug_info.final_residual_power   = final_residual_power;
end

function debug_info = fill_debug_init_failed(init_theta, Lc)
    debug_info.outer_iter_used      = 0;
    debug_info.theta_trace          = nan(0, Lc);
    debug_info.angle_update_trace   = nan(0, 1);
    debug_info.init_theta           = init_theta;
    debug_info.init_failed          = true;
    debug_info.guard_applied        = false;
    debug_info.final_residual_power = NaN;
end
```

#### 9.4.3 关键实施提示（5 条）

1. **`A` 的 steering 约定必须与 `doa_root_music_array` 一致**：用 `exp(-1j * 2π · posN · d · sind(θ) / λ)`。如果反号，对消方向会反，整个迭代就发散。
2. **`cancel_matrix * y` 是 N×N 乘 N×T 的密集矩阵乘法**，对 N=64 / T=260 不构成性能瓶颈（每个样本 ≈ 16640 复乘）。**不要**为了"优化"逐 `t` 算 `β(t)` 然后逐 `t` 减 —— 矩阵化版本快 5~10 倍。
3. **`doa_root_music_array(y_residual, ..., Lc=1)` 单目标版本必须直接复用 proto6 的函数**。proto6 函数签名已经支持任意 Lc，**不要新建一个 "Lc=1 专用版本"**。
4. **`min_sep_guard = 0.05 deg` 是经验值**。如果 bw/10 间隔本身就是 0.28°，guard 0.05° 远小于真实间隔，安全；如果未来想测 bw/20（≈0.14°），guard 要相应调小。
5. **`max_outer_iter = 6` 是经验上足够的迭代轮数**。proto6 给出的初值已经很接近真值，多数样本 2~3 轮就收敛。如果 `outer_iter_used` 平均接近 6，说明收敛慢，可能需要排查初值或迭代逻辑。

#### 9.6.3 proto9 主结论 A/B/C 处置

| 情况 | proto9 SNR90 | proto9 RMSE | 处置 |
|------|-------------|-------------|------|
| **A：理想（论文最优）** | 至少 1 档下移 (例如 `[12, 14, 18, 20]` 或 `[14, 14, 18, 20]`) | 持续 ≤ proto6_array | proto9 升级为方向 D 正式创新点。论文章节："基于稳定子空间的迭代精细化"，重点写它对 FFT-II 失败的工程化救援 |
| **B：温和** | 与 proto6 完全持平 `[14, 16, 20, 22]` | RMSE 在 SNR ≥ 20 dB 区持续低于 proto6 (3~10%) | proto9 作为「子空间域 RELAX 精细化」附加创新点，论文章节重点在 RMSE 和 iter_used 趋势上 |
| **C：失败** | 严格 > proto6（哪怕一档）或 init_failed_rate > 5% | 不重要 | proto9 归档，写一段失败说明：可能是迭代发散 / guard 触发率过高 / 初值传递问题 |

> **实际预期**：A 的概率约 40~50%，B 的概率约 40%，C 约 10%。bw/9 / bw/10 出 A 的概率最大（因为初值在小间隔区抖动空间大，迭代能修正）。

#### 9.6.4 诊断量合理性（必须）

- **`mean_outer_iter`**：典型应在 `2.5 ~ 5` 之间。若 = `6`（最大值）说明很多样本没收敛，需检查 `angle_tol_stop_deg` 是否过严；若 < 2 说明大量样本第一轮就 stop，可能是 proto6 初值已经够准（这是好事）。
- **`init_failed_rate`**：必须 **< 1%**（高 SNR 应接近 0）。如果显著 > 0，proto6 在该 SNR 下都给不出有限角，proto9 自然继承失败。
- **`guard_applied_rate`**：典型应 **< 5%**。如果显著高（如 > 20%），说明 proto9 频繁触发坍缩 guard，迭代不稳定，需 debug。
- **`mean_final_residual_power`**：应随 SNR 升高而单调下降，且应**显著低于** baseline `y_clean` 中两目标对消后理论残差（即纯噪声功率）。如果 final_residual_power 不下降，说明迭代没真正减小残差。

#### 9.6.5 失败安全检查（迭代发散红线）

满足任一条立即停下排查：

1. `init_failed_rate > 10%`（proto6 都崩了，proto9 没意义）
2. `guard_applied_rate > 30%`（迭代频繁坍缩，算法不稳定）
3. proto9 SNR90 比 proto6_array **严格高 ≥ 2 档**（迭代发散，不是抽样波动）
4. `mean_outer_iter` 在所有档位全 = `max_outer_iter`（从不收敛）

## 十、Prototype 10 实施指令（圆柱阵适配：解决"阵列脱钩"硬伤）

### 10.1 目标

```matlab
cfg.beam.sectorHalf = 60;          % 工作扇区半角 (deg)
cfg.beam.subNaz     = 2 * floor(cfg.beam.sectorHalf / cfg.arr.dPhi) + 1;
                                    % = 2 * floor(60/1.875) + 1 = 2*32 + 1 = 65
```

完整推导链：

| 步骤 | 物理含义 | 数值 |
|---|---|---|
| `sectorHalf` | 工作扇区半角 | 60° |
| `floor(sectorHalf / dPhi)` | 中心列单侧能放下的整列数 | `floor(60 / 1.875)` = 32 |
| `subNaz` | 工作子阵列数 = 中心 1 列 + 两边各 32 列 | `2*32 + 1` = **65 列** |
| `(subNaz - 1) * dPhi` | 工作子阵实际跨越的方位角范围 | `64 * 1.875°` = **120°**（即 ±60°）|
| `arr_cyl(cfg, azCtr)` | 围绕方位中心 `azCtr` 在 192 列圆周阵上挑出连续 65 列 | 输出 `arrInfo.colsAct` 是 65 维列索引向量 |
| 工作子阵规模 | 65 列 × 32 层 | 2080 阵元 |

**结论**：你的雷达**每个 CPI 看的就是这 65 列 × 32 层 = 2080 个阵元（覆盖 azCtr ± 60°）**。Step 5 / 6 / 7 / 8 的所有"工作子阵"指的都是这同一个 65×32 子阵。

#### 10.2.3 关键几何观察

1. **圆周方向相邻列的弧长 ≈ 0.44 λ**，小于 λ/2，**满足空间采样定理**。这是好消息——可以把弧形阵列子段近似为 ULA，不会因为采样间隔造成 ambiguity。

2. **整段 65 列（跨 120°）当 ULA 近似会严重失效**：弧形两端的列已经偏离视轴 60°，曲率失配大到无法接受。具体计算：
   - 中心列在视轴方向投影：`R * (1 - cos(0°))` = 0 m（参考点）
   - 边缘列在视轴方向投影：`R * (1 - cos(60°))` = 0.2 m
   - 这意味着边缘列与中心列在视轴方向上**有 0.2 m 的几何错位**（≈ 6.7 λ），远超 ULA 允许的"几乎共线"假设

3. **DOA 估计的解决方案**：从 65 列工作子阵里**再次取中心 N_arc 列做 DOA**，而不是用整段 65 列。这是"工作子阵选取"和"DOA 算法子阵选取"的**两级嵌套子阵选择**：

   ```
   全阵 192 列  ──[选 120° 工作扇区]──▶  65 列 × 32 层 (Step 5/6 工作子阵)
                                              │
                                              │ [选中心 N_arc 列 × 1 层]
                                              ▼
                                          DOA 子阵 (Step 8 算法输入)
   ```

4. **N_arc 取值的权衡**：

   | N_arc | DOA 子阵跨度 | 边缘列偏轴角 | 视轴投影错位 | ULA 近似质量 | 阵元增益 |
   |---|---|---|---|---|---|
   | 16 | 28.1° | 14° | ≈ 0.012 m (0.4λ) | 很好 | 低（-6 dB vs 64） |
   | 32 | 58.1° | 29° | ≈ 0.051 m (1.7λ) | 可接受（推荐） | 中（-3 dB vs 64） |
   | 48 | 88.1° | 44° | ≈ 0.113 m (3.8λ) | 已经差 | 高 |
   | 64 | 118.1° | 59° | ≈ 0.195 m (6.5λ) | 完全失效 | 最高 |

   **推荐 N_arc = 32**：跨度 ≈ 60°，平衡阵元增益与曲率失配。论文里也可以同时跑 N_arc=16/32/48 三档，画一张"N_arc vs SNR90 / mean_bias"对比图，刻画失配边界。

### 10.4 Prototype 10.B 完整版：Phase Mode Excitation（可选升级）

#### 10.4.1 适用条件

只在以下情况才做 10.B：

- 10.A 已经验证圆柱阵上算法可跑
- 论文档次需要更高（冲优秀硕士）
- 还有 2~3 天时间

#### 10.4.2 核心思想

Phase Mode Excitation (PME) 是 UCA (Uniform Circular Array) 上的标准技术，可以把圆柱阵单层的 UCA 通过一个解析变换映射为虚拟 ULA。

**关键公式**：

对单层 UCA（N 个等间距分布在圆周上的阵元），定义 phase mode m：

```
v_m = (1 / sqrt(N)) · Σ_{n=0}^{N-1} y_n · exp(-j · 2π · m · n / N)
```

向量化：`v = F^H · y`，其中 F 是 N×N DFT 矩阵。

经过 PME 变换后，phase mode 序列 `{v_m}` 近似具有 Vandermonde 结构（这是 Bessel 函数展开的结果，参见 Belloni-Koivunen 2007）：

```
v_m ≈ j^m · J_m(2π·R/λ · cos(el)) · exp(j·m·az)
```

把 `(j^m · J_m(...))` 当作"已知调制因子"除掉后，剩下的 `exp(j·m·az)` 就是标准 Vandermonde 结构，可以直接套 Root-MUSIC。

#### 10.4.3 关键步骤

```matlab
function v = uca_to_virtual_ula(y, N, R, lambda, el_assumed_deg)
    F = exp(-1j * 2*pi * (0:N-1)' * (0:N-1) / N) / sqrt(N);
    v_raw = F' * y;                           % N x T_snap

    % 用 Bessel 函数去除调制（el_assumed 是俯仰先验）
    m_idx = (0:N-1)' - floor(N/2);            % 中心对齐 mode index
    bessel_factor = (1j).^m_idx .* besselj(m_idx, 2*pi*R/lambda * cosd(el_assumed_deg));
    v = v_raw ./ bessel_factor;
end
```

注意：

- PME 严格只适用于 UCA（圆形），你的圆柱阵每一层就是一个 UCA
- 多层叠加可以用 z 方向 FFT 转换（标准方法）
- PME 在低 phase mode（|m| < 2π·R/λ · cos(el)）有效，高 mode 因 Bessel 函数过小而数值不稳定

#### 核心算法改造（关键的"信号生成 vs DOA 估计"双标）

你必须实现两条**互不一致**但都正确的逻辑：

**逻辑 A：信号生成必须用真实圆柱阵 3D 坐标**（保真度）

```matlab
% 1) 选取工作子阵 + 取中间层 + 取中心 N_arc 列
arrInfo = arr_cyl(cfg, azCtr_deg);         % azCtr_deg 推荐设 0
iel_select = round(cfg.arr.Nel / 2);       % = 16
col_mid = round((cfg.beam.subNaz + 1) / 2);   % = 33
N_arc = 32;
col_select = (col_mid - N_arc/2 + 1) : (col_mid + N_arc/2);   % 65 列里取中心 32 列

% 2) 提取这 32 个阵元的真实 3D 坐标 (N_arc x 3)
pos_xyz = [arrInfo.XAct(col_select, iel_select), ...
           arrInfo.YAct(col_select, iel_select), ...
           arrInfo.ZAct(col_select, iel_select)];

% 3) 用真实坐标计算 steering vector
%    单位指向矢量按方位 az 和俯仰 el 的笛卡尔分解
unit_a = [cosd(el_a)*cosd(az_a), cosd(el_a)*sind(az_a), sind(el_a)];
A_a = exp(-1j * 2*pi / cfg.arr.lambda * pos_xyz * unit_a.');   % N_arc x 1

% 4) 生成 y = A * s + n
```

**逻辑 B：DOA 估计假装阵列是 ULA**（套用 proto6 现成算法）

```matlab
d_eq = 2*pi*cfg.arr.R / cfg.arr.Naz;       % ≈ 0.01309 m
K_fbss = 28;                                % FBSS 子阵长度，按 N_arc - 4 经验取

```

**为什么这两条互不一致还正确**：

- 逻辑 A 是真实物理，保证仿真的"地面真相"和你雷达系统建模一致；
- 逻辑 B 是工程近似，因为弧段足够小时 ULA 假设近似成立；
- 两者的不一致就是"圆柱阵适配失配"的来源，**论文里要明确说，不能藏**。

#### 失败决策树（按问题类型处置）

**第 1 类问题：sanity check fail（doa = NaN 或偏差很大）**

按以下顺序排查：

1. 检查 `pos_xyz` 是否正确（打印第 1 行和最后一行的坐标，肉眼对照圆柱阵几何）
2. 检查 `cfg.arr.lambda` 是否正确（必须是 0.030 m，不是 ULA 的 0.111 m）
3. 检查 `d_eq` 计算是否正确（`2*pi*0.4/192` ≈ 0.01309 m）
4. 检查 K_fbss 是否合理（必须 ≤ N_arc - 4，推荐 = 28）
5. 检查信号生成的 `exp(-1j * 2*pi / lambda * pos_xyz * unit.')` 的矩阵维度（结果必须是 N_arc × 1，不是 1 × N_arc）
6. 跑一个**极简单**的对照：N_arc=32 真正 ULA + 真正 ULA steering（不用 pos_xyz），看 doa_root_music_array 是否能给出 < 0.05° 的精度。如果不能，是 doa_root_music_array 调用方式错了；如果能，是圆柱阵几何转换错了。

**第 2 类问题：视轴附近 tol_rate 上不去（公平性回归第 1 条不过）**

- 检查 d_eq 是否真的与"信号生成时圆周方向相邻列实际看到的相位差"匹配。可以打印某个高 SNR 样本的 y 在相邻列之间的相位差，看是不是 `2*pi*d_eq*sin(theta_target)/lambda`。
- 如果不匹配，说明 d_eq 的物理含义没对上。圆柱阵小段弧的"等效间距"严格说是切线方向投影距离，不一定恰好等于弧长。但在视轴附近这两者差异极小（< 1%），如果你算出的 d_eq 偏差大于 5%，需要重审公式。

**第 3 类问题：`pure_ula_root_music_reference` 不能复现纯 ULA 历史结果**

- 这是底层校验失败，说明公平对比框架本身有问题
- 重点查 noise_power 计算公式（`mean(abs(y_clean(:)).^2) / 10^(snr/10)`），与 proto6 是否完全一致
- 重点查 rng seed 设置是否在每个 (iSep, iSNR, metkl_num) 三元组开头都调用了

**第 4 类问题：脚本跑得很慢（> 8 小时）**

- 不要"优化"算法本身。Prototype 10 的目的是验证，不是加速
- 可以临时减小 Metkl=100 看趋势，但提交结果必须 Metkl=200

#### 11.2.2 Stochastic CRLB（Unconditional / Gaussian Sources）

对 ULA、`Lc` 个高斯源、`T_snap` 快拍、加性高斯白噪声场景，DOA 估计的 stochastic CRLB 为：

```
CRLB(θ) = (σ_n^2 / (2·T_snap)) · {Re[(D^H · P_A^⊥ · D) ⊙ (P_s · A^H · R^{-1} · A · P_s)^T]}^{-1}
```

其中：

| 符号 | 含义 |
|---|---|
| `θ` | `Lc × 1` 真实角度向量 |
| `A` | `N × Lc` steering 矩阵 |
| `D` | `N × Lc`，`D(:, k) = ∂a(θ_k)/∂θ_k` |
| `P_A^⊥` | `I - A · (A^H·A)^{-1} · A^H` 噪声子空间投影 |
| `P_s` | `Lc × Lc` 源协方差矩阵 |
| `R` | `N × N` 阵元域真协方差 = `A·P_s·A^H + σ_n^2·I` |
| `σ_n^2` | 噪声方差 |
| `⊙` | Hadamard 积（按元素相乘） |
| `^T` | 矩阵转置（注意，不是共轭转置） |
| `Re[·]` | 取实部 |

**对你的相干等幅双目标场景**：`P_s = [1, 1; 1, 1]`（秩 1），需要做特殊处理（见 11.2.3）。

#### 11.2.3 相干源 CRLB 的退化处理

严格相干源（`P_s` 秩 1）下，标准 stochastic CRLB 退化为不存在唯一解。文献处理方式：

1. **方法 A（推荐）**：用 `P_s = [1, ρ; ρ*, 1]`，`|ρ| < 1`，让 ρ → 1，看 CRLB 趋势
2. **方法 B**：用 Conditional CRLB（也叫 Deterministic CRLB），对未知确定信号建模：

```
CRLB_cond(θ) = (σ_n^2 / 2) · {Re[(D^H · P_A^⊥ · D) ⊙ (S·S^H / T_snap)^T]}^{-1}
```

其中 `S` 是 `Lc × T_snap` 源信号矩阵。**对相干源场景，Conditional CRLB 不退化**，可以直接用。

**强烈推荐方法 B**，因为：

- 你的源信号是确定性的 `s1 = s2 = exp(j·2π·fc·t)`（脚本里写死了）
- Conditional CRLB 在相干源下数值稳定
- 文献里"相干源 CRLB 对比"通常用 Conditional CRLB

#### 11.3.2 函数 F1：`compute_crlb_conditional.m`

```matlab
function crlb_deg = compute_crlb_conditional(theta_deg, S, sigma_n2, N, d, lambda, T_snap)
% Conditional (Deterministic) CRLB for DOA estimation.
%
% 输入：
%   theta_deg   1 x Lc       真实角度 (deg)
%   S           Lc x T_snap  确定性源信号矩阵
%   sigma_n2    scalar       噪声方差
%   N           scalar       阵元数
%   d           scalar       阵元间距 (m)
%   lambda      scalar       波长 (m)
%   T_snap      scalar       快拍数
% 输出：
%   crlb_deg    1 x Lc       每个角度的 CRLB 标准差 (deg)

    Lc = numel(theta_deg);
    n_idx = (0:N-1)';

    % Steering matrix A 和导数 D
    A = zeros(N, Lc);
    D = zeros(N, Lc);
    for k = 1:Lc
        a_k = exp(-1j * 2*pi * d * n_idx * sind(theta_deg(k)) / lambda);
        A(:, k) = a_k;
        % d a(θ)/d θ = a(θ) ⊙ (-j · 2π · d/λ · n · cos(θ))
        D(:, k) = a_k .* (-1j * 2*pi * d / lambda * n_idx * cosd(theta_deg(k))) * (pi/180);
        % 末尾的 (pi/180) 是把 1/rad 转成 1/deg
    end

    % 噪声子空间投影
    P_perp = eye(N) - A * pinv(A);

    % 源协方差估计 (确定性源)
    P_s_est = S * S' / T_snap;

    % Fisher 信息矩阵
    FIM = (2*T_snap / sigma_n2) * real( (D' * P_perp * D) .* (P_s_est.') );

    % CRLB = inv(FIM)
    crlb_matrix = inv(FIM);
    crlb_var = real(diag(crlb_matrix));        % 单位 deg^2
    crlb_deg = sqrt(max(crlb_var, 0)).';       % 1 x Lc
end
```

```matlab
clc; clear; close all;

script_dir = fileparts(mfilename('fullpath'));

snr_list = data.snr_list;

bw_64 = roundn(bw_64, -1);

nsep = numel(sep_factor_list);
nsnr = numel(snr_list);
crlb_deg = zeros(nsep, nsnr);

for iSep = 1:nsep
    theta_sep = bw_64 / sep_factor_list(iSep);
    theta_a = theta_c - theta_sep/2;
    theta_b = theta_c + theta_sep/2;
    theta_true = [theta_a, theta_b];

    % 与 proto6 信号生成完全一致
    t = linspace(0, 1, T_snap);
    fc = 2.7e9;
    s1 = exp(1j * 2*pi * fc * t);
    s2 = exp(1j * 2*pi * fc * t);
    S = [s1; s2];

    % 估算 y_clean 平均功率（与 proto6 noise_power 公式一致）
    A_a = exp(-1j * 2*pi * d * (0:N-1)' * sind(theta_a) / lambda);
```

### 11.4 验收标准

#### 11.4.1 必须通过的硬指标

1. **CRLB 数值合理性**：
   - CRLB 应随 SNR 单调下降（log-log 直线，斜率 -1/2）
   - 高 SNR (≥ 24 dB) 下 CRLB ≤ 0.05°
   - 低 SNR (< 0 dB) 下 CRLB 可能很大（甚至发散），是正常的
2. **proto6 RMSE ≥ CRLB**：
   - 这是 CRLB 的定义（任何无偏估计的方差下界）
   - 如果 proto6 RMSE < CRLB，说明你 CRLB 公式写错了（最常见的 bug：源协方差 P_s 没取对，或 sigma_n2 单位不对）
3. **高 SNR 下 proto6 RMSE / CRLB 应趋于一个常数**：
   - 理论最优算法（DML）在高 SNR 下 RMSE / CRLB → 1
   - Root-MUSIC 在高 SNR 下通常 RMSE / CRLB ≈ 1.5~3（取决于场景）
   - 如果你的 ratio < 1.5 或 > 5，需检查

#### 11.4.2 论文里要写的关键句

```markdown
图 X 给出 proto6 (FBSS + Root-MUSIC) 在四个典型 sep_factor 下的 RMSE 与 Conditional CRLB 对比。
可以观察到：

(1) proto6 的 RMSE 始终高于 CRLB，符合理论下界；

    这与 MUSIC 类算法的低 SNR 失稳现象一致；
(4) 上述结果验证了 proto6 在工程参数下的近优性能。
```
