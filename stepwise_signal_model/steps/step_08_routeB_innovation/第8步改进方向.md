## 一、当前瓶颈分析

从第 8 步的所有失败原型 (proto1 ~ proto5a-refined2) 已经把瓶颈定位清楚：

1. **不是 FFT 中心估计的问题**：proto4 / 4a / 4b / 4e 各种 FFT 中心 / 窗口修补，在 `proto4_line_fair_compare` (seed 锁定，同样本) 下 SNR90 都没真正超过真值中心 baseline。所以「沿 FFT 引导窗口」这条线本身上限有限，已经触顶。
2. **不是协方差残差对消能解的**：proto3 直接劣化到全零。相干双目标的 Rss 是秩 2 但两个特征向量在 beamspace 下高度耦合，单峰秩 1 强对消会把共享结构打掉。
3. **不是 FFT-II 论文复现能直接拯救**：proto5a / 5a-refined / 5a-refined2 三轮都没把残差里的次目标稳定显露出来。论文 (4-14)~(4-19) 那套泄漏建模在相干等幅、间隔小于 1 个波束宽度的场景里，第一次主峰对消后残差里的次峰几乎都是旁瓣泄漏而非真目标。
4. **真正暴露出来的金线索**：在 `proto5a` 里顺手做的 `root_music_reference`（FBSS 后直接 Root-MUSIC）在同 seed 公平对比下系统性领先 Route B 主线 2 dB：

| 角间隔 | Route B (baseline_true_centerT) | Root-MUSIC (FBSS + root) | 差距 |
| ------ | ------------------------------- | ------------------------ | ---- |
| bw/7   | 16 dB                           | **14 dB**                | -2   |
| bw/8   | 18 dB                           | **16 dB**                | -2   |
| bw/9   | 22 dB                           | **20 dB**                | -2   |
| bw/10  | 24 dB                           | **22 dB**                | -2   |

也就是说整个 SNR90 曲线被整体下移 2 dB，且不依赖 FFT 中心、不依赖任何启发式窗口。这条线索几乎已经是论文创新点的现成答案 —— 只是它目前在 `proto5a_refined2` 里被当作参考线而不是创新点。

## 二、创新方向总览

按论文价值 × 实现难度排序。

### 方向 A（最优先，几乎稳赢）：把后端从 grid-MUSIC 换成 Root-MUSIC

核心改动只有一处：Route B 的「1D MUSIC 网格搜索 + 局部峰检测」换成「在 FBSS 后的协方差上做多项式求根 (Root-MUSIC)」。

- **原理**：Root-MUSIC 把谱峰搜索变成 `2(K-1)` 阶多项式求根，避开网格量化、避开峰提取启发式（这是 proto3 / proto5 失败的另一个隐藏代价：peak picking 在双峰即将合并时极不稳定）。
- **两个子版本**：
  - **A-array**：在 `Rss (K_fbss × K_fbss)` 上直接 Root-MUSIC（已被 proto5a 验证）
  - **A-beamspace**：在 `Rb (M_b × M_b)` 上做 Beamspace Root-MUSIC（Zoltowski 等的做法）。`Tk = QR(Wcenter)` 是近似酉矩阵，对应的 beamspace steering `b(θ) = Tk' * a(θ)` 仍是 K 个空间频率分量的线性组合，可走 "Root-MUSIC in Beamspace"。
- **预期收益**：把 Route B 整体 SNR90 下移 2 dB（A-array 已经被实验证实）。
- **论文表述**："Array-domain FBSS Combined with Beamspace Root-MUSIC for Coherent Targets"。

> 这是最该立刻拿来当主创新点的方向，几乎零风险，已有公平实验背书。

### 方向 B（次优先，论文里非常成熟）：在 FBSS 之上加 Toeplitz 结构投影

核心改动：在 `mssp_array_fb` 输出的 `Rss` 上再做一次 Toeplitz 平均（或 Toeplitz 投影），再喂给后端。

- **原理**：ULA + 时间平稳模型下，真协方差 R_ss 严格 Toeplitz；有限快拍 + FBSS 残留的非 Toeplitz 分量纯粹来自噪声。强制 Toeplitz 化等于多做一次免费平均，能进一步降低 R_ss 第二特征值附近的扰动方差。
- **实现**（待方向 A 跑通后引入）：

  ```matlab
  function R_t = toeplitz_project(R)
      K = size(R, 1);
      r = zeros(K, 1);
      for k = 0:K-1
          r(k+1) = mean(diag(R, k));
      end
      R_t = toeplitz(r);
      R_t = 0.5 * (R_t + R_t');
  end
  ```
- **预期收益**：在 `bw/8 ~ bw/10` 这类 `lambda2/noise_floor ≈ 1` 的区域，能再压 1 ~ 2 dB。
- **可叠加性**：可以叠加在方向 A 上 ⇒ "Toeplitz-FBSS + Beamspace Root-MUSIC"，论文上是一个干净的组合创新点。

### 方向 C（论文常见，但有上限）：把酉变换 / Unitary 处理引入 Route B

核心改动：用酉变换 `Q` (Lee 1981) 把复数 `R_b` 变成实对称矩阵，再做实数特征分解 + 实 Root-MUSIC。

- **原理**：酉变换天然把 forward-backward 平均内置进了实数化，等效再做一次 FB 平均，并且实数 eig 比复数 eig 在小快拍下数值更稳定。
- **预期收益**：和方向 B 量级类似，能再压 1 ~ 2 dB；比方向 B 略弱，但论文上 "Unitary X-MUSIC / Unitary ESPRIT" 是很标准的写法，文献多、好引用。

### 方向 D（如果想把 FFT-II 那条线救回来）：把 RELAX 用在 Route B 的子空间上，而不是 FFT 域

proto5 那套 FFT-II 失败的原因已经在第 8 步实验记录里定位：FFT 域的主峰对消显露不出真次峰。但 RELAX 思路 (Li & Stoica) 本身没错，只是不该在 FFT 谱上做，而应该在 Route B 已经稳定的子空间上做。

- **核心改动**：
  1. 用 Route B 给出 `(θ_1^{(0)}, θ_2^{(0)})` 作为初值
  2. 固定 `θ_2`，在阵元域对 y 直接做最小二乘对消 `y' = y - a(θ_2) * β_2`
  3. 在 y' 上重做 FBSS + Root-MUSIC，更新 `θ_1`
  4. 角色互换，更新 `θ_2`
  5. 迭代到收敛
- **跟 proto3 的区别**：proto3 在 beamspace 协方差上做秩 1 强对消，会破坏双目标共享结构；这里在阵元域 y 上做对消，FBSS 仍然完整作用在新 y' 上，没有破坏 FBSS 的解相干前提。
- **预期收益**：在中高 SNR 区可能再压 1 dB；论文创新点表述 "Subspace-domain RELAX refinement" 或 "Iterative array-domain cancellation"。

### 方向 E（备选，理论上最强但实现重）：DML / WSF 把 Route B 当初值

- **核心改动**：以 Route B 输出做初值，用 Newton / Gauss-Newton 解：

  `min_{θ_1, θ_2}  trace[(I - A(θ) · A(θ)^+) · R_ss]`

- **预期收益**：高 SNR 下逼近 CRLB；低 SNR 下不一定优于 Root-MUSIC，且对初值敏感（但 Route B 给的初值通常够用）。
- **论文表述**：「ML refinement of FBSS-Beamspace MUSIC」，分量重，但创新点足。

### 执行优先级

1. 方向 A 正式化为 Prototype 6（**本文第三部分给出完整执行指令**）
2. 方向 B 叠加到 Prototype 6 (proto6 跑通后再做)
3. 视效果再决定是否做方向 D / C / E

### 4.3 函数 F1：`doa_root_music_array.m`

#### 4.3.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_array(y, K, lambda, d, Lc)
% Array-domain Root-MUSIC after FBSS.
% 输入：
%   y       N x T_snap   阵元域快拍
%   K       FBSS 子阵长度 (与 Route B 保持一致, e.g. 56)
%   lambda  波长 (m)
%   d       阵元间距 (m, 与 Route B 保持一致, e.g. 0.047)
%   Lc      目标数 (=2)
% 输出：
%   doa_value   1 x Lc       两个 DOA 估计 (deg, 升序)；失败时返回 NaN
%   debug_info  struct       字段如下：
%       .eigvals             K x 1     Rss 特征值降序
%       .lambda2_over_noise  scalar    第 2 大特征值 / 噪声底均值 (Lc+1..Lc+min(K-Lc,6))
%       .num_inside_roots    scalar    单位圆内的根数
%       .root_distance_unit  Lc x 1    被选中根的 abs(|z|-1) 值 (越小越好)
```

#### 4.3.2 实现要点（参照 `proto5a_refined2` 第 851-900 行 `estimate_root_music_from_fbss_cov`）

```matlab
% 1) 阵元域协方差
T_snap = size(y, 2);
Rxx = (y * y') / T_snap;
Rxx = 0.5 * (Rxx + Rxx');

% 2) 阵元域 FBSS（直接调用 step_07_5_*/mssp_array_fb.m）
Rss = mssp_array_fb(Rxx, K);
Rss = 0.5 * (Rss + Rss');

% 3) 特征分解
[V, D] = eig(Rss);
eigvals = real(diag(D));
[eigvals, idx] = sort(eigvals, 'descend');
V = V(:, idx);

% 4) 噪声子空间投影矩阵
En = V(:, Lc+1:end);
C  = En * En';

% 5) 构造 Root-MUSIC 多项式系数 (沿对角线 C 求和)
M = K;
poly_coeffs = zeros(1, 2*M - 1);
lag_list = -(M-1):(M-1);
for ii = 1:numel(lag_list)
    poly_coeffs(ii) = sum(diag(C, lag_list(ii)));
end

% 6) 求根
rts = roots(fliplr(poly_coeffs));
inside_roots = rts(abs(rts) < 1);

% 7) 选距单位圆最近的 Lc 个根
if numel(inside_roots) < Lc
    doa_value = nan(1, Lc);
    return;
end
[~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
chosen = inside_roots(ord(1:Lc));

% 8) 角度反推 (steering 用 exp(-j*2*pi*d*n*sin(theta)/lambda))
omega = angle(chosen);
sin_theta = -(lambda / (2*pi*d)) * omega;
if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
    doa_value = nan(1, Lc);
    return;
end
sin_theta = min(max(real(sin_theta), -1), 1);
doa_value = sort(asind(sin_theta)).';
doa_value = doa_value(:).';

% 9) 诊断信息
noise_start = Lc + 1;
noise_end   = min(numel(eigvals), Lc + 6);
noise_floor = mean(eigvals(noise_start:noise_end));
debug_info.eigvals             = eigvals;
debug_info.lambda2_over_noise  = eigvals(2) / max(noise_floor, eps);
debug_info.num_inside_roots    = numel(inside_roots);
debug_info.root_distance_unit  = abs(abs(chosen) - 1);
```

#### 4.3.3 与现有 proto5a 实现的差异

- 现有 `estimate_root_music_from_fbss_cov(Rss, D, lambda, d)` 是接收 `Rss` 的版本；
- 新函数接收原始 `y`，内部完成 `Rxx → FBSS → Root-MUSIC`，方便论文图直接引用一个函数；
- 增加了 `debug_info`，便于后续诊断 `lambda2/noise_floor`。

### 4.4 函数 F2：`doa_root_music_beamspace.m`

#### 4.4.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace(y, K, Tk, lambda, d, Lc)
% Beamspace Root-MUSIC after FBSS + centerT projection.
% 输入：
%   y       N x T_snap   阵元域快拍
%   K       FBSS 子阵长度
%   Tk      K x M_b      centerT 投影矩阵 (与 Route B 一致, M_b = center_beam_count)
%   lambda, d, Lc        同 doa_root_music_array
% 输出：
%   doa_value   1 x Lc   两个 DOA 估计 (deg, 升序)；失败时返回 NaN
%   debug_info  struct   字段：
%       .eigvals_rb        M_b x 1
%       .lambda2_over_noise scalar
%       .num_inside_roots  scalar
%       .root_distance_unit Lc x 1
```

#### 4.4.2 实现要点

> 注意：`Tk` 是 QR 之后的近似酉矩阵，不是严格 Vandermonde。在 beamspace 域做 Root-MUSIC 需要先求出 `b(θ) = Tk' * a(θ)` 与 `θ` 的解析关系。这里采用「**对 `b(θ)^H E_n_b E_n_b^H b(θ)` 的多项式系数**」做法：

```matlab
% 1) 同 F1 步骤 1~2 得到 Rss (K x K)
T_snap = size(y, 2);
Rxx = (y * y') / T_snap;
Rxx = 0.5 * (Rxx + Rxx');
Rss = mssp_array_fb(Rxx, K);
Rss = 0.5 * (Rss + Rss');

% 2) 投影到 beamspace
%    注意：与 DOA_three_music_new_route_centerT.m 保持完全相同的投影方向
%    Tk 用 exp(+j ...), aK 用 exp(-j ...)，故 Rb = Tk.' * Rss * conj(Tk)
Rb = Tk.' * Rss * conj(Tk);
Rb = 0.5 * (Rb + Rb');

% 3) 特征分解
[Vb, Db] = eig(Rb);
eigvals_rb = real(diag(Db));
[eigvals_rb, idx] = sort(eigvals_rb, 'descend');
Vb = Vb(:, idx);
En_b = Vb(:, Lc+1:end);

% 4) 把 beamspace 噪声子空间映回阵元域
%    M(θ) = aK(θ)^H * conj(Tk) * En_b * En_b^H * Tk.' * aK(θ)
%        = aK(θ)^H * Q * aK(θ),  Q := conj(Tk) * (En_b En_b^H) * Tk.'
Q = conj(Tk) * (En_b * En_b') * Tk.';
Q = 0.5 * (Q + Q');                  % 数值对称化

% 5) 沿对角线求多项式系数 (复 Toeplitz 形式)
M = K;
poly_coeffs = zeros(1, 2*M - 1);
lag_list = -(M-1):(M-1);
for ii = 1:numel(lag_list)
    poly_coeffs(ii) = sum(diag(Q, lag_list(ii)));
end

% 6) 求根、选根、反推角度 (与 F1 步骤 6~8 完全一致)
rts = roots(fliplr(poly_coeffs));
inside_roots = rts(abs(rts) < 1);
if numel(inside_roots) < Lc
    doa_value = nan(1, Lc);
    return;
end
[~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
chosen = inside_roots(ord(1:Lc));

omega = angle(chosen);
sin_theta = -(lambda / (2*pi*d)) * omega;
if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
    doa_value = nan(1, Lc);
    return;
end
sin_theta = min(max(real(sin_theta), -1), 1);
doa_value = sort(asind(sin_theta)).';
doa_value = doa_value(:).';

% 7) 诊断
noise_start = Lc + 1;
noise_end   = min(numel(eigvals_rb), Lc + 6);
noise_floor = mean(eigvals_rb(noise_start:noise_end));
debug_info.eigvals_rb            = eigvals_rb;
debug_info.lambda2_over_noise    = eigvals_rb(2) / max(noise_floor, eps);
debug_info.num_inside_roots      = numel(inside_roots);
debug_info.root_distance_unit    = abs(abs(chosen) - 1);
```

> **实施提示**：`Q = conj(Tk) * En_b * En_b' * Tk.'` 仍然是 `K x K`，所以多项式仍然是 `2(K-1)` 阶。这是把 beamspace 噪声子空间「拉回」阵元域 ULA 流形后再做 Root-MUSIC，比直接在 `Rb` 上做更稳。如果之后想做严格 beamspace Root-MUSIC（在 `M_b` 阶多项式上），需要 `Tk` 严格满足某种 Vandermonde 性质，目前 QR 出来的 `Tk` 不满足，**先按本写法实现**。

#### 6.3.1 函数签名

```matlab
function R_t = toeplitz_project(R)
% Hermitian Toeplitz projection.
%
% 在 Hermitian 矩阵 R 上做沿对角线平均，强制其满足 Toeplitz 结构。
% 适用于 ULA + 时间平稳假设下的协方差矩阵：真协方差严格 Toeplitz，
% 有限快拍 / FBSS 残留的非 Toeplitz 分量来自噪声扰动，强制 Toeplitz
% 化等于做一次免费平均。
%
% 输入：
%   R   K x K   Hermitian 矩阵 (典型为 FBSS 后的 Rss 或 beamspace Rb)
% 输出：
%   R_t K x K   Hermitian Toeplitz 矩阵
```

#### 6.3.2 完整实现

```matlab
function R_t = toeplitz_project(R)
    K = size(R, 1);
    if size(R, 2) ~= K
        error('toeplitz_project: R must be square.');
    end

    % 1) 数值厄米化 (保险)
    R = 0.5 * (R + R');

    % 2) 沿各上对角线求均值
    %    diag(R, k) 与 diag(R, -k) 互为共轭，所以只需要算 k = 0..K-1
    r = zeros(K, 1);
    for k = 0:K-1
        r(k+1) = mean(diag(R, k));
    end

    % 3) 对角线必须是实数 (Hermitian 矩阵的对角线一定实)
    r(1) = real(r(1));

    % 4) toeplitz(c) 在 MATLAB 中等价于 toeplitz(c, conj(c)),
    %    自动产生 Hermitian Toeplitz 矩阵
    R_t = toeplitz(r);

    % 5) 数值厄米化 (再次保险)
    R_t = 0.5 * (R_t + R_t');
end
```

#### 6.3.3 实施提示

- `toeplitz(r)` 在 MATLAB 中传入复数列向量时，会自动用 `conj(r)` 作为第一行，产生 Hermitian Toeplitz 矩阵；
- 步骤 3 强制 `r(1)` 实数化是为了消除浮点误差，不是算法本身要求；
- 不要试图用 `for` 循环手动填矩阵 —— 直接 `toeplitz(r)` 比 `for` 快几十倍，且没有越界风险；
- 这个函数同样可以作用在 `Rb` (beamspace) 上，但 **beamspace 投影后协方差严格意义上不是 Toeplitz**（因为 `Tk' * (Toeplitz Rss) * conj(Tk)` 一般不再是 Toeplitz）。所以在 beamspace 版本里，正确做法是 **先对 Rss 做 Toeplitz 投影，再投影到 beamspace**，而不是反过来。proto7 的两个函数 F2 / F3 都遵循这个顺序。

### 6.4 函数 F2：`doa_root_music_array_toeplitz.m`

#### 6.4.2 完整实现

```matlab
function [doa_value, debug_info] = doa_root_music_array_toeplitz(y, K, lambda, d, Lc)
    % 1) 阵元域协方差
    T_snap = size(y, 2);
    Rxx = (y * y') / T_snap;
    Rxx = 0.5 * (Rxx + Rxx');

    % 2) 阵元域 FBSS (复用 step_07_5_*/mssp_array_fb.m)
    Rss_pre = mssp_array_fb(Rxx, K);
    Rss_pre = 0.5 * (Rss_pre + Rss_pre');

    % 2.5) Toeplitz 投影 (proto7 的唯一新增步骤)
    Rss = toeplitz_project(Rss_pre);

    % 3~9) 与 doa_root_music_array.m 完全一致
    [V, D] = eig(Rss);
    eigvals = real(diag(D));
    [eigvals, idx] = sort(eigvals, 'descend');
    V = V(:, idx);

    En = V(:, Lc+1:end);
    C  = En * En';

    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(C, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed(Rss_pre, Rss, eigvals, Lc);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed(Rss_pre, Rss, eigvals, Lc);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 9) 诊断信息：同时记录 Toeplitz 投影前后的 lambda2/noise
    debug_info = fill_debug_info(Rss_pre, Rss, eigvals, Lc, chosen);
end

function debug_info = fill_debug_info(Rss_pre, Rss_post, eigvals_post, Lc, chosen)
    [~, D_pre] = eig(0.5 * (Rss_pre + Rss_pre'));
    eigvals_pre = sort(real(diag(D_pre)), 'descend');

    debug_info.eigvals                   = eigvals_post;
    debug_info.eigvals_pre_tp            = eigvals_pre;
    debug_info.lambda2_over_noise        = compute_lambda2_over_noise(eigvals_post, Lc);
    debug_info.lambda2_over_noise_before_tp = compute_lambda2_over_noise(eigvals_pre, Lc);
    debug_info.lambda2_over_noise_after_tp  = debug_info.lambda2_over_noise;
    debug_info.num_inside_roots          = numel(chosen);
    debug_info.root_distance_unit        = abs(abs(chosen) - 1);
    debug_info.toeplitz_residual_norm    = norm(Rss_pre - Rss_post, 'fro') / max(norm(Rss_pre, 'fro'), eps);
end

function debug_info = fill_debug_failed(Rss_pre, Rss_post, eigvals_post, Lc)
    debug_info = fill_debug_info(Rss_pre, Rss_post, eigvals_post, Lc, []);
    debug_info.root_distance_unit = nan(Lc, 1);
end

function r = compute_lambda2_over_noise(eigvals, Lc)
    if numel(eigvals) < Lc + 1
        r = NaN;
        return;
    end
    noise_start = Lc + 1;
    noise_end   = min(numel(eigvals), Lc + 6);
    noise_floor = mean(eigvals(noise_start:noise_end));
    r = eigvals(2) / max(noise_floor, eps);
end
```

### 6.5 函数 F3：`doa_root_music_beamspace_toeplitz.m`

#### 6.5.1 函数签名

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace_toeplitz(y, K, Tk, lambda, d, Lc)
% Beamspace Root-MUSIC after FBSS + Toeplitz projection + centerT projection.
%
% 与 doa_root_music_beamspace.m 完全相同，除了在 FBSS 后、centerT 投影前
% 插入一次 Toeplitz 投影。
%
% 注意：Toeplitz 投影必须发生在 Rss 上（阵元域）而非 Rb 上（beamspace 域），
% 因为 Rb = Tk' * Rss * conj(Tk) 一般不是 Toeplitz，对 Rb 做 Toeplitz 投影
% 既无理论依据，又会破坏其物理含义。
%
% 输入 / 输出：与 doa_root_music_beamspace.m 一致，debug_info 额外字段同 F2。
```

#### 6.5.2 完整实现

```matlab
function [doa_value, debug_info] = doa_root_music_beamspace_toeplitz(y, K, Tk, lambda, d, Lc)
    % 1) 阵元域协方差
    T_snap = size(y, 2);
    Rxx = (y * y') / T_snap;
    Rxx = 0.5 * (Rxx + Rxx');

    % 2) 阵元域 FBSS
    Rss_pre = mssp_array_fb(Rxx, K);
    Rss_pre = 0.5 * (Rss_pre + Rss_pre');

    % 2.5) Toeplitz 投影 (proto7 唯一新增步骤，必须在 Rss 上做，不是 Rb)
    Rss = toeplitz_project(Rss_pre);

    % 3) 投影到 beamspace (与 doa_root_music_beamspace.m 一致)
    Rb = Tk.' * Rss * conj(Tk);
    Rb = 0.5 * (Rb + Rb');

    % 4) 特征分解
    [Vb, Db] = eig(Rb);
    eigvals_rb = real(diag(Db));
    [eigvals_rb, idx] = sort(eigvals_rb, 'descend');
    Vb = Vb(:, idx);
    En_b = Vb(:, Lc+1:end);

    % 5) 把 beamspace 噪声子空间映回阵元域
    Q = conj(Tk) * (En_b * En_b') * Tk.';
    Q = 0.5 * (Q + Q');

    % 6) 求根、选根、反推角度 (与 doa_root_music_beamspace.m 完全一致)
    M = K;
    poly_coeffs = zeros(1, 2*M - 1);
    lag_list = -(M-1):(M-1);
    for ii = 1:numel(lag_list)
        poly_coeffs(ii) = sum(diag(Q, lag_list(ii)));
    end

    rts = roots(fliplr(poly_coeffs));
    inside_roots = rts(abs(rts) < 1);

    if numel(inside_roots) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rss_pre, Rss, eigvals_rb, Lc);
        return;
    end

    [~, ord] = sort(abs(abs(inside_roots) - 1), 'ascend');
    chosen = inside_roots(ord(1:Lc));

    omega = angle(chosen);
    sin_theta = -(lambda / (2*pi*d)) * omega;
    if sum(abs(sin_theta) <= 1 + 1e-9) < Lc
        doa_value = nan(1, Lc);
        debug_info = fill_debug_failed_bs(Rss_pre, Rss, eigvals_rb, Lc);
        return;
    end

    sin_theta = min(max(real(sin_theta), -1), 1);
    doa_value = sort(asind(sin_theta)).';
    doa_value = doa_value(:).';

    % 7) 诊断
    debug_info = fill_debug_info_bs(Rss_pre, Rss, eigvals_rb, Lc, chosen);
end

function debug_info = fill_debug_info_bs(Rss_pre, Rss_post, eigvals_rb, Lc, chosen)
    [~, D_pre] = eig(0.5 * (Rss_pre + Rss_pre'));
    eigvals_rss_pre  = sort(real(diag(D_pre)), 'descend');
    [~, D_post] = eig(0.5 * (Rss_post + Rss_post'));
    eigvals_rss_post = sort(real(diag(D_post)), 'descend');

    debug_info.eigvals_rss_after_tp      = eigvals_rss_post;

    debug_info.lambda2_over_noise_before_tp = compute_lambda2_over_noise(eigvals_rss_pre, Lc);
    debug_info.lambda2_over_noise_after_tp  = compute_lambda2_over_noise(eigvals_rss_post, Lc);
    debug_info.num_inside_roots          = numel(chosen);
    debug_info.root_distance_unit        = abs(abs(chosen) - 1);
    debug_info.toeplitz_residual_norm    = norm(Rss_pre - Rss_post, 'fro') / max(norm(Rss_pre, 'fro'), eps);
end
```

### 6.7 验收标准

跑完 proto7 后按以下顺序检查。

#### 6.7.1 公平性回归（必须）

- `baseline_routeB_centerT_grid_music` 的 SNR90 (abs01) 必须为 `[16, 18, 22, 24]` dB；
- `proto4e_fft_piecewise_grid_music` 的 SNR90 (abs01) 必须为 `[18, 18, 22, 24]` dB；
- `proto6_array_root_music` 的 SNR90 (abs01) 必须为 `[14, 16, 20, 22]` dB。

> base_seed 用 20260523（与 proto6 的 20260522 错开），所以个别 SNR 点的 tol_rate 可能 ±0.01~0.02 波动，但 SNR90 离散门槛**必须**与上述完全一致。如不一致，先检查 mssp_array_fb 调用、QR 构造、噪声功率计算是否与 proto6 完全相同。

#### 6.7.2 方向 B 主结论（核心判断）

下表给出三种可能结果的处置方案：

| 情况 | proto7_array SNR90 | 处置 |
|------|-------------------|------|
| **A：理想** | 至少在 `bw/9` 或 `bw/10` 下移 ≥ 1 档 (例如 `[14, 16, 18, 22]` 或 `[14, 16, 20, 20]`) | proto7 作为正式组合创新点保留，命名为 "Toeplitz-FBSS + Root-MUSIC"；论文里写成 proto6 + proto7 组合创新 |
| **B：温和** | 与 proto6 完全持平 `[14, 16, 20, 22]`，但 RMSE 或 lambda2 诊断量持续改善 | proto7 仍可保留为「数值稳定性增强」附加创新点；论文里写成「Toeplitz 投影在分辨门槛之上对 RMSE / lambda2 有持续改善」 |
| **C：失败** | proto7_array SNR90 比 proto6 还差 | proto7 直接归档；写一段失败原因说明：可能是当前 T_snap=260 已经把 lambda2 充分打开，Toeplitz 投影带来的免费平均效益不足以体现 |

> 实际经验：proto7 大概率落在「A」和「B」之间。情况 A 的概率最高的位置是 `bw/9` 这一档（lambda2/noise 在临界区，Toeplitz 平均最有效）。

#### 6.7.3 诊断量合理性（必须）

- `lambda2_over_noise_post_tp` 应**严格 ≥** `lambda2_over_noise_pre_tp`（在多数 SNR 点上）。如果反过来，说明 Toeplitz 投影实现错了。
- `toeplitz_residual_norm` 应随 SNR 升高而单调下降（高 SNR 下 Rss 已经接近 Toeplitz，残差应小）。在低 SNR 下应 ≤ 0.5 量级，在高 SNR 下应 ≤ 0.1。
- `proto7_array` 与 `proto7_beam` 的 SNR90 应基本持平（与 proto6 array/beam 同结论），如果差距 ≥ 2 dB 说明 beamspace 版本里 Toeplitz 顺序写错了（必须先 Toeplitz 再 beamspace，不是反过来）。
