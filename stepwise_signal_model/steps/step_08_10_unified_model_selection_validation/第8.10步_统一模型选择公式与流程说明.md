# 第8.10步 统一模型选择公式与流程说明

## 1. 输入观测

输入来自第 8.8 shared-center 接口：`Y_work(q,m,p)`，其中 `q=1...65`，`m=1...32`，`p=1...T_snap`，默认 `T_snap=Np=32`，默认不启用 Doppler de-rotation。two separated coarse peaks 仍为 out-of-scope。

评分子阵固定为 `K_phi_score=20`、`K_z_score=8`，从 65x32 工作子阵中心抽取，列优先向量化：`Y_score(:,p)=subarray_20x8(:,:,p)(:)`，`M=160`。

样本协方差：`R=(1/T)Y_score Y_score^H`，并记录 `R_norm=||R||_F`。若 `R_norm` 过小，直接输出 `H0_boundary/low_confidence`。

## 2. steering 定义

`a(theta,el)` 使用与第 8.7/8.8 一致的圆柱阵 calibrated steering，并统一归一化：`a_bar=a/max(||a||_2,eps)`。H1/H2/H3 全部使用归一化 steering。

## 3. 通用残差评分

对任意 `A in C^(M x K)`：`P_A=A inv(A^H A + eps_reg I) A^H`，`eps_reg=1.0e-08`。

`sigma2_A=max(real(trace((I-P_A)R))/max(M-K,1),0)`。

`R_A=P_A R P_A + sigma2_A (I-P_A)`。

`J(A)=||R-R_A||_F^2 / max(||R||_F^2,eps)`。J 越小，模型解释能力越强。

## 4. H1/H2/H3/H0

- H1: `A1=a_bar(theta,el)`，搜索 `theta_center+[-2,2] deg` 与 `el=-2:0.5:12 deg`，top 5 局部细化。
- H2: `A12=[a(theta_a,el_c),a(theta_b,el_c)]`，构造 `Q=A12 inv(chol(A12^H A12+eps_reg I))`，在 `B=Q^H R Q` 中取最大特征向量，得到 `c=Q u_max/max(||Q u_max||,eps)`，以 `J(c)` 评分。
- H3: `A3=[a(theta_a,el_a),a(theta_b,el_b)]`。候选只来自 2D projection/MUSIC-like 峰及两两组合，不使用真值；最终仍用 `J(A3)` 选择。
- H0: 当绝对残差过大、模型 margin 太小或改善量不足时，输出 `H0_boundary`。

## 5. 默认选择规则

`improve_21=(J1-J2)/max(J1,eps)`，`improve_31=(J1-J3)/max(J1,eps)`，`improve_32=(J2-J3)/max(J2,eps)`。

`model_margin=(J_sorted(2)-J_sorted(1))/max(J_sorted(1),eps)`。

默认阈值：`tau_improve=0.05`，`tau_model_margin=0.02`，`tau_h3_over_h2=0.03`，`tau_abs_residual=0.35`。

本轮同时输出 default threshold 与 small sweep；Metkl=30 时 mc=1:10 为 calibration，mc=11:30 为 validation。quick mode 只作为趋势检查。
