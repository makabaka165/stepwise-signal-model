# IP Repository

This directory contains the generated Step14.2 Vivado Custom IP repository.

Current IP:

```text
ip_repo/dbf_axis_ip_1_0/
VLNV = user.org:radar:dbf_axis:1.0
```

The package is generated by `vivado/package_dbf_axis_ip.tcl`. Re-run that script
to rebuild the package; do not manually maintain staged HDL copies.

Tracked package contents:

- `component.xml`
- `hdl/` with 5 Step13 arithmetic RTL files and 5 Step14 AXIS/IP RTL files
- `data/` with 14 Step14.1 W ROM `.mem` files
- `xgui/`
- `source_manifest.csv`
- `package_manifest.csv`

The package intentionally excludes Y replay vectors and Z expected vectors.
Those remain validation-only files under `results_step14_dbf_ip_soc_integration/`.

This repository does not contain a Vivado project, Block Design, AXI DMA, PS,
bitstream, XSA, HWH, board validation, or full FPGA backend.
