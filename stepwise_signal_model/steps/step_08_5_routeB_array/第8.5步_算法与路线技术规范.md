## 二、几何与坐标系

### 2.1 全阵列几何（来自 `core/array/arr_cyl.m`）

```
全阵列：192 列 × 32 层 = 6144 阵元

列 iaz ∈ [1, 192] 的方位角：
    phiCol(iaz) = (iaz - 1) / 192 · 360°    (单位：度)

层 iel ∈ [1, 32] 的高度：
    zRow(iel) = (iel - 1) · dz              (从 0 开始)

阵元 (iaz, iel) 的 3D 坐标：
    X(iaz, iel) = R · cos(phiCol(iaz))
    Y(iaz, iel) = R · sin(phiCol(iaz))
    Z(iaz, iel) = zRow(iel)
```

### 2.2 工作子阵选取（120° 扇区）

```
输入：azCtr_deg（当前关注方位中心），第 8.5 步统一取 0°

phiRel(iaz) = wrap180(phiCol(iaz) - azCtr_deg)
colCtr = argmin |phiRel|                          (最接近 azCtr 的列号)
halfSpan = (subNaz - 1) / 2 = 32
colsAct = (colCtr - 32 .. colCtr + 32) mod 192    (65 个连续列)

工作子阵规模：65 列 × 32 层 = 2080 阵元，跨方位 120°
```

### 2.3 DOA 子阵选取（第 8.5 步在本级动手）

```
从工作子阵 65 列中取中心 N_arc 列：
    col_mid = round((subNaz + 1) / 2) = 33
    col_select = (col_mid - N_arc/2 + 1) : (col_mid + N_arc/2)
                = 33 - N_arc/2 + 1 .. 33 + N_arc/2

例：N_arc=32 → col_select = 18:49（工作子阵的第 18~49 列）

DOA 子阵 3D 坐标：
    X3d = arrInfo.XAct(col_select, 1:Nel)         [N_arc × Nel]
    Y3d = arrInfo.YAct(col_select, 1:Nel)
    Z3d = arrInfo.ZAct(col_select, 1:Nel)

关键性质：
    - 每列 n 的 (X3d(n, :), Y3d(n, :)) 不依赖层号（圆柱阵每列共面）
    - Z3d(:, m) 不依赖列号（每层水平）
```

## 三、信号模型（双标设计）

### 3.1 双标设计理念

第 8.5 步的核心设计是**"信号生成保真 + DOA 估计近似"双标**：

| 阶段 | 模型 | 公式 |
|---|---|---|
| **逻辑 A**：信号生成 | **真实圆柱阵 3D 几何**（保真） | `A = exp(-j·2π/λ · pos_xyz · u)` |
| **逻辑 B**：DOA 估计 | **等效 ULA**（套用 proto6 算法） | `A_ula = exp(-j·2π/λ · n·d_eq · sin(az))` |

**两者不一致**就是"圆柱阵适配失配"的来源，论文里必须诚实说明。

### 3.2 完整 y_clean 生成公式（逻辑 A）

给定目标 (az_a, el_a) 和 (az_b, el_b)，两个源信号 s1(t)、s2(t)，工作子阵的 3D 坐标 X3d、Y3d、Z3d ∈ R^{N_arc × Nel}：

```
单位指向矢量：
    u_a = [cos(el_a) cos(az_a), cos(el_a) sin(az_a), sin(el_a)]
    u_b = [cos(el_b) cos(az_b), cos(el_b) sin(az_b), sin(el_b)]

相位矩阵（每阵元独立内积）：
    phase_a(n, m) = X3d(n,m) · u_a(1) + Y3d(n,m) · u_a(2) + Z3d(n,m) · u_a(3)
    phase_b(n, m) = X3d(n,m) · u_b(1) + Y3d(n,m) · u_b(2) + Z3d(n,m) · u_b(3)

Steering 矩阵：
    A_a_2d = exp(-j · 2π/λ · phase_a)    [N_arc × Nel]
    A_b_2d = exp(-j · 2π/λ · phase_b)    [N_arc × Nel]

干净观测（未归一化未合成）：
    y_clean_2d(n, m, t) = A_a_2d(n, m) · s1(t) + A_b_2d(n, m) · s2(t)
    维度：[N_arc × Nel × T_snap]
```

### 3.3 源信号定义

```
基础：
    s1(t) = exp(j · 2π · fc · t)
    s2(t) = exp(j · 2π · fc · t + j · Δφ)     (Δφ 单位弧度)

完全同相（proto10 ~ proto15.A + verify A）：Δφ = 0
准相干（verify B/C）：Δφ ∈ {5°, 15°, 30°, 60°, 90°, 180°}
```

### 3.4 噪声生成

```
y_clean 是 [N_arc × Nel × T_snap] 三维张量

每个 (iSep, iSNR) 单元的噪声功率：
    σ² = mean(|y_clean_2d(:)|²) / 10^(SNR/10)

噪声样本（每个 metkl_num 独立）：
    rng(seed_now)
    noise_2d = sqrt(σ²/2) · (randn(size(y_clean_2d)) + j·randn(size(y_clean_2d)))

最终 2D 观测：
    y_2d = y_clean_2d + noise_2d                  [N_arc × Nel × T_snap]
```

### 3.5 seed 公式（所有原型/实验严格统一）

```
seed_now = base_seed + 100000 · iSep + 1000 · iSNR + metkl_num
        = 20260601 + 100000 · iSep + 1000 · iSNR + metkl_num

例外路线（verify A K=24 / verify B Δφ=15 等）通过共享同样的 seed_now 确保自检数值严格一致。

proto6 64ch replay 用独立 seed：
    seed_64 = base_seed + 100000 · (iSep_64 + 100) + 1000 · iSNR_64 + metkl_num
```

### 4.2 mssp_array_fb（前向-后向空间平滑 FBSS）

**输入**：阵元域协方差 `Rxx ∈ C^{N×N}`，子阵长度 `K < N`

**输出**：FBSS 后协方差 `Rfbss ∈ C^{K×K}`

**数学定义**：

```
设 N 维 ULA 阵列协方差为 Rxx，分为 P = N - K + 1 个长度 K 的重叠子阵：
    Rxx[p..p+K-1, p..p+K-1] = R_p ,  p = 1..P

前向平滑：
    Rf = (1/P) · Σ_{p=1}^{P} R_p

前向-后向平滑（FBSS）：
    Rfbss = 0.5 · (Rf + J · Rf^* · J)

其中 J 是反对角单位矩阵（fliplr(eye(K))），共轭 Rf^* 取元素共轭

最后厄米对称化：
    Rfbss := 0.5 · (Rfbss + Rfbss^H)
```

**对相干源的作用**：

对完全相干源 `Ps = |s|² · v v^H, v = [1, 1]^T`，秩 1。FBSS 通过子阵间相位累积把秩 1 协方差恢复到秩 ≤ min(P, Lc)。**P_sub 越大，恢复越彻底**；P_sub 接近 Lc 时几乎不工作。

**关键不变性**：FBSS 严格假设阵列是 Vandermonde 流形（连续 K 列子阵 steering 满足 `A_p = D^(p-1) · A_1`）。**圆柱阵弧段不严格满足这条**，但在视轴归一化后近似成立（N_arc=32 时失配 < 3%，N_arc=64 时失配 17%）。

### 4.3 doa_root_music_array（FBSS + Root-MUSIC）

**输入**：阵元域数据 `y ∈ C^{N×T_snap}`，FBSS 子阵长度 K，波长 λ，间距 d，信源数 Lc

**输出**：`doa ∈ R^{1×Lc}`（角度，度，已排序）

**算法流程**（严格按 `doa_root_music_array.m` 实现）：

```
步骤 1：协方差估计
    Rxx = (y · y^H) / T_snap
    Rxx := 0.5 · (Rxx + Rxx^H)              (厄米对称化)

步骤 2：FBSS
    Rss = mssp_array_fb(Rxx, K)             [K × K]
    Rss := 0.5 · (Rss + Rss^H)

步骤 3：特征分解 + 噪声子空间
    [V, D] = eig(Rss)
    eigvals = sort(real(diag(D)), 'descend')
    V := V(:, sort_idx)
    En = V(:, Lc+1 : end)                   [K × (K-Lc)]
    C = En · En^H                            [K × K]

步骤 4：构造 Root-MUSIC 多项式系数
    M = K
    poly_coeffs(ii) = sum(diag(C, lag_list(ii))),  lag_list = -(M-1):(M-1)
    多项式：P(z) = Σ_{l=-(M-1)}^{M-1} c_l · z^{l+M-1}
    （共 2M-1 个系数）

步骤 5：求根 + 选择"模最接近 1 的 Lc 个内部根"
    rts = roots(fliplr(poly_coeffs))
    inside_roots = rts(|rts| < 1)
    chosen = inside_roots 中 |·| 最接近 1 的 Lc 个

步骤 6：根 → 角度
    omega = angle(chosen)
    sin_theta = -(λ / (2π · d)) · omega     ← 注意负号
    doa = sort(asind(sin_theta))            [1 × Lc]

容错：
    - 若 numel(inside_roots) < Lc → 返回 NaN
    - 若 |sin_theta| > 1+1e-9 → 返回 NaN
    - 若 doa 含非有限值 → 返回 NaN
```

**debug_info 字段**：
- `eigvals`：特征值（降序）
- `lambda2_over_noise = eigvals(2) / mean(eigvals(Lc+1:Lc+6))`（信号 vs 噪声子空间分离度）
- `num_inside_roots`：单位圆内的根数
- `root_distance_unit`：被选根的 `|·| - 1` 绝对值

### 4.4 grid-MUSIC（proto15.A 主脚本内自包含实现）

**输入**：阵元域数据 `y ∈ C^{N×T_snap}`，FBSS 后的噪声子空间 `En ∈ C^{K×(K-Lc)}`，搜索流形 `a(az) ∈ C^{K}`

**输出**：`doa ∈ R^{1×Lc}`

**算法流程**：

```
步骤 1-3：同 Root-MUSIC（Rxx → FBSS → 子空间分解）

步骤 4：构造谱搜索网格
    angle_grid = (azCtr - bw_eq) : 0.005° : (azCtr + bw_eq)  约 2000 点

步骤 5：MUSIC 谱
    for ii = 1..|angle_grid|:
        az = angle_grid(ii)
        a_test(ii) = 单位化 (a(az))
        den = real(a_test^H · (En · En^H) · a_test)
        Pmu(ii) = 1 / max(den, eps)

步骤 6：峰值检测（FindLocalPeak_NoEdge_Fun）
    [_, peak_inds] = FindLocalPeak_NoEdge_Fun(Pmu)
    peak_inds 按谱值降序
    若 numel(peak_inds) < Lc → doa = NaN
    否则 doa = sort(angle_grid(peak_inds(1:Lc)))
```

**proto15.A 中两种流形**（路线 2 vs 路线 3）：

```
真实弧段流形（路线 2）：
    a_real(az) = exp(-j · 2π/λ · (X_K · cos(az) + Y_K · sin(az))) ⊙ conj(A_ref_K)
    (X_K, Y_K 是 FBSS 等效中心子阵的 K 列 X/Y 坐标)

ULA Vandermonde 流形（路线 3，消融）：
    a_ula(az) = exp(-j · 2π · d_eq · (0:K-1)^T · sin(az) / λ)
```

**与 Root-MUSIC 的关键差异**：
- Root-MUSIC 通过多项式根强行给出 K 个根（必返回 Lc 个角度）
- grid-MUSIC 依赖峰值检测；**完全同相小间隔时两峰合并成单峰** → 返回 NaN
- grid-MUSIC 失败模式：`peaks = 1` 而非 `peaks = 0`

## 五、第 8.5 步专属处理

### 5.1 视轴方向相位归一化

**动机**：圆柱阵阵元在视轴方向 (azCtr=0°) 的几何距离不一致（因为 X 坐标依赖 cos(phi)），即便信号从视轴入射，y 在阵元间的相位也不是 ULA 的常相位。直接喂给 ULA-Root-MUSIC 会让 sanity 失败。

**公式**：

```
视轴单位矢量（取 el=0）：
    u_ref = [cos(0°) cos(azCtr), cos(0°) sin(azCtr), sin(0°)]
          = [1, 0, 0]   (当 azCtr=0)

视轴 steering 矩阵：
    A_ref_2d(n, m) = exp(-j · 2π/λ · (X3d(n,m) · u_ref(1) + Y3d(n,m) · u_ref(2)))

归一化后干净观测：
    y_clean_ref_2d = conj(A_ref_2d) ⊙ y_clean_2d    (逐元素相乘)

归一化后 az=azCtr 入射时阵元间相位为 0（满足 ULA 常相位假设）
```

**适用边界**：弧段跨度 ≤ ±30° 时近似成立。N_arc=32 跨 58° 安全；N_arc=64 跨 118° 边界严重失配（17%）。

### 5.2 32 层俯仰相干合成（proto14 核心创新）

**动机**：proto10 v2 只用 32 列 × 1 层 = 32 阵元，浪费了 31 层信号。proto14 用全部 32 层做相干合成，理论 SNR 增益 10·log10(32) = 15.0515 dB。

**公式**：

```
输入：y_2d ∈ C^{N_arc × Nel × T_snap}（视轴归一化后）
假设：el_assumed 已知（来自上游 Step 5 的 2D 检测）

俯仰 steering（仅 z 分量；每列 n 的 (X, Y) 在 32 层间相同）：
    z_col = Z3d(1, :)^T = (0, dz, 2dz, ..., (Nel-1)dz)^T    [Nel × 1]
    steer_el = exp(-j · 2π/λ · z_col · sin(el_assumed))     [Nel × 1]

合成权向量（含归一化）：
    W = steer_el^H / sqrt(Nel)                              [1 × Nel]

合成（对每列 n 独立做）：
    y_combined(n, t) = W · y_2d(n, :, t)                    [标量]
    维度：y_combined ∈ C^{N_arc × T_snap}
```

**MATLAB 实现**（`combine_layers_local` 函数）：

```matlab
function y_combined = combine_layers_local(y_2d, Z3d, lambda, el_assumed)
    Nel = size(y_2d, 2);
    z_col = Z3d(1, :).';
    steer_el = exp(-j * 2*pi / lambda * z_col * sind(el_assumed));
    W = steer_el' / sqrt(Nel);                              % 1 x Nel
    tmp = W * reshape(permute(y_2d, [2, 1, 3]), Nel, []);   % 1 x (N_arc*T_snap)
    y_combined = reshape(tmp, size(y_2d, 1), size(y_2d, 3));
end
```

**等效 steering**（合成后）：

```
当 el_actual = el_assumed 时（理想情况）：
    a_combined(n; az) = sqrt(Nel) · exp(-j · 2π/λ · (X3d(n,1)·cos(az) + Y3d(n,1)·sin(az))) ⊙ conj(A_ref_1d(n))

等价于：N_arc 元的"虚拟单层" steering，且每个虚拟阵元的功率增益 Nel = 32（线性域），对应 SNR 增益 15.05 dB

当 el_actual ≠ el_assumed 时：
    增益降低 |sinc(π·dz·(sin(el_assumed) - sin(el_actual))/λ · Nel)|² 倍
    proto14 实测：el 失配 2° 引入 clean coherent loss = 6.74 dB
```

### 5.3 等效 ULA 间距 d_eq 的选取

```
d_eq = 2π · R / Naz = arc_dist ≈ 0.01309 m
```

**物理含义**：圆周方向相邻列的弧长。

**约定**：DOA 估计阶段，无论 N_arc=32/48/64，都用同一个 d_eq。

**误差边界**：视轴归一化后，弧段近似 ULA 的失配量级为 `1 - sin(phi_edge)/phi_edge`：

| N_arc | phi_edge | sin(phi)/phi | 失配 |
|---:|---:|---:|---:|
| 32 | 29.06° (0.507 rad) | 0.974 | 2.6% |
| 48 | 44.06° (0.769 rad) | 0.911 | 8.9% |
| 64 | 59.06° (1.031 rad) | 0.832 | 17% |

### 5.4 FBSS 等效中心子阵的 X/Y 坐标（grid-MUSIC 用）

proto15.A 路线 2 的真实流形需要"FBSS 后等效中心子阵"的 X/Y 坐标：

```
P_sub = N_arc - K_fbss + 1
p_mid = round((P_sub + 1) / 2)
col_center = col_select(p_mid : p_mid + K_fbss - 1)   [K_fbss 列全局列号]
X_K = arrInfo.XAct(col_center, iel_select)            [K_fbss × 1]
Y_K = arrInfo.YAct(col_center, iel_select)
A_ref_K = exp(-j · 2π/λ · (X_K · cos(azCtr) + Y_K · sin(azCtr)))   [K_fbss × 1]
```

**注意**：FBSS 严格上"等效协方差"不对应任何一组真实坐标，这里取中央子阵的坐标是工程近似。proto15.A 否定流形假设的实验结果证明这个近似在视轴附近可接受。

### 6.2 每个原型的完整算法路径

#### proto10 v2：单层弧段 + ULA Root-MUSIC

```
1. 几何：arr_cyl → 65 列工作子阵 → 取中心 32 列 × 取中间层 iel=16
2. 信号生成（逻辑 A）：y_clean_single = A_a_2d(:, 16, :) · s1 + A_b_2d(:, 16, :) · s2
3. 视轴归一化：y = conj(A_ref_2d(:, 16)) ⊙ y_clean_single
4. 加噪：y += noise
5. DOA（逻辑 B）：[doa, dbg] = doa_root_music_array(y, K=28, λ=0.030, d=0.01309, Lc=2)
6. 退化判定：~all(isfinite(doa)) || max|sort(doa) - sort(true)| > 1°
```

#### proto14 路线 2：32 层俯仰相干合成（主创新）

```
1. 几何：同 proto10 v2
2. 信号生成（逻辑 A）：y_clean_2d ∈ C^{32 × 32 × 260}
3. 视轴归一化：y_clean_2d_ref = conj(A_ref_2d) ⊙ y_clean_2d
4. 加噪：y_2d = y_clean_2d_ref + noise_2d
5. 俯仰合成：y_combined = combine_layers_local(y_2d, Z3d, λ, el_assumed=0)   [32 × 260]
6. DOA（逻辑 B）：[doa, dbg] = doa_root_music_array(y_combined, K=28, λ=0.030, d=0.01309, Lc=2)
```

#### proto14b N=48/64：扩孔径扫描

```
与 proto14 路线 2 相同，但：
    N_arc = 48 → col_select 扩到 48 列；K_fbss = 44
    N_arc = 64 → col_select 扩到 64 列；K_fbss = 60
    其他不变
```

#### proto15.A 路线 2：grid-MUSIC + 真实弧段流形

```
步骤 1-5 同 proto14 路线 2，得到 y_combined ∈ C^{32 × 260}

步骤 6（关键差异）：
    Rxx = y_combined · y_combined^H / T_snap
    Rfbss = mssp_array_fb(Rxx, K=28)
    [V, D] = eig(Rfbss); En = V(:, 3:end)

步骤 7：grid-MUSIC 谱
    P_sub = 5; p_mid = 3
    col_center = col_select(3:30) (28 列)
    X_K, Y_K = arrInfo.XAct/YAct(col_center, 16)
    A_ref_K = exp(-j · 2π/λ · (X_K + 0))    (azCtr=0 时 sin=0)

    for az in (-bw_eq : 0.005° : +bw_eq):
        a_test = exp(-j · 2π/λ · (X_K·cos(az) + Y_K·sin(az))) ⊙ conj(A_ref_K)
        a_test = a_test / |a_test|
        Pmu(az) = 1 / real(a_test^H · En · En^H · a_test)

步骤 8：FindLocalPeak_NoEdge_Fun(Pmu) → 前 2 个峰
    若峰数 < 2 → doa = NaN (proto15.A sep=10 的主要失败模式)
```

#### verify A：K_fbss 扫描

```
与 proto14 路线 2 完全相同，外层循环 K_fbss ∈ [28, 24, 20, 16]
每档 K_fbss 改 doa_root_music_array(y_combined, K_fbss, ..., 2) 的第二个参数
其他不变；K=28 档严格重现 proto14 路线 2 数值
```

#### verify B：Δφ 扫描

```
与 proto14 路线 2 完全相同，外层循环 Δφ ∈ [0, 5, 15, 30, 60, 90, 180]°
每档 Δφ 改 s2 = exp(j·2π·fc·t + j·deg2rad(Δφ))
重新计算 noise_power = mean(|y_clean_2d|²) / 10^(SNR/10)（Δφ 改变 y_clean 总功率）
其他不变；Δφ=0 档严格重现 proto14 路线 2 数值
```

#### verify C：K_fbss × Δφ 联合

```
双层外循环 K_fbss ∈ [28, 24] × Δφ ∈ [0, 5, 15, 30]°
8 个组合每个跑 proto14 路线 2 main loop
共享 seed，确保 3 个自检：
    (K=28, Δφ=0) = proto14 路线 2
    (K=28, Δφ=15) = verify B Δφ=15
    (K=24, Δφ=0) = verify A K=24
```

## 八、数学约定速查（避免歧义）

### 8.1 Steering vector 符号约定

```
约定：a(θ) = exp(-j · 2π/λ · pos · u)        ← 负指数

对应 Root-MUSIC 求根：
    sin_theta = -(λ / 2πd) · angle(root)     ← 同号匹配

若改用 a(θ) = exp(+j · ...) 则求根公式要变 sin = +(λ/2πd)·angle(root)

第 8 步算法函数 doa_root_music_array.m 内部假设负指数约定（line 73）：
    sin_theta = -(lambda / (2 * pi * d)) * omega;
```

### 8.2 矩阵维度约定

| 量 | 维度 | 备注 |
|---|---|---|
| y（阵元域数据） | N × T_snap | N 行阵元，T 列快拍 |
| Rxx | N × N | 厄米对称 |
| Rfbss | K × K | 子阵长度 K |
| V, En | K × (K-Lc), En 是噪声子空间 | En 列向量张成噪声子空间 |
| C = En · En^H | K × K | 用于 Root-MUSIC 多项式 |
| steering a | K × 1 | 列向量 |
| 3D 坐标 X3d/Y3d/Z3d | N_arc × Nel | 行为列，列为层 |
| u（单位指向矢量） | 1 × 3 | 行向量 [cos·cos, cos·sin, sin] |
| y_2d | N_arc × Nel × T_snap | 三维张量 |
| y_combined | N_arc × T_snap | 合成后退回二维 |

### 8.3 SNR 定义

```
SNR_dB = 10 · log10(P_signal / P_noise)

其中：
    P_signal = mean(|y_clean(:)|²)   (over 所有阵元、所有时间)
    P_noise = σ² = P_signal / 10^(SNR_dB/10)

噪声生成：
    n(i, t) = sqrt(σ²/2) · (randn + j·randn)
    每个 (i, t) 独立同分布

注意：proto14 报告的"32 层合成 SNR 增益 15.05 dB" 是 10·log10(Nel)，是 y_combined 相对 y_single（取中间层）的功率比。它**不是 SNR 提升 15 dB**——因为 noise 也合成了一次。但对相干信号，合成增益线性叠加；对独立 noise，合成增益是 sqrt(Nel)，所以等效 SNR 提升确实 10·log10(Nel)。
```

### 8.4 退化样本判定

```
是否退化（来自 is_valid_doa_success.m）：
    degraded = ~all(isfinite(doa)) OR max|sort(doa) - sort(true)| > 1°

是否 tol_abs 成功：
    |sort(doa) - sort(true)| < tol_deg (=0.1°)  逐分量

是否 tol_rel 成功：
    |sort(doa) - sort(true)| < tol_rel_ratio · theta_sep  (=0.25 · sep)
```

### 8.5 SNR90 定义

```
对每个 (route, sep_factor) 单元，扫 snr_list，找第一个 tol_rate ≥ 0.9 的 SNR：
    snr90 = min{SNR_dB | tol_rate(SNR_dB) ≥ 0.9}

若 tol_rate 全程 < 0.9 → snr90 = NaN
```
