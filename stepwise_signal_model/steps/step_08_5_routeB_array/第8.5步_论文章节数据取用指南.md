#### 关键叙事点

1. **观察核心矛盾**：proto6 (64 元 ULA, K=56, P=9) work；proto14 (32 元等效, K=28, P=5) 不 work。两者全孔径相位差几乎相同（0.064 周期），差异只在 P_sub
2. **FBSS 数学**：对完全同相相干源 `Ps = |s|²[1 1; 1 1]`，FBSS 恢复秩需要 P_sub 个子阵的相位累积；P_sub=5 时相位累积不足

| SNR90 (dB) | -4 | **10** | NaN | NaN | NaN | NaN |
| 总退化率 | 0.00% (全部 sep) | | | | | |

### 物理解释（必写）

Δφ=180° 时 s2 = -s1，y_clean = a·s1 + b·s2 = (a-b)·s1：
- sep_factor 小（角度大）：a-b 各分量大，y_clean 有意义 → 可估计
- sep_factor 大（角度小）：a ≈ b → a-b ≈ 0 → 信号自相消 → 等效 SNR 趋于 -∞
- 这是**双目标 destructive interference** 物理边界，不是算法失败

### 关键叙事点

1. **Δφ=0° 和 Δφ=180° 是两个物理稀缺的数学边界**
2. **Δφ=180° 不是算法问题**：sep ≥ 3 时 a-b ≈ 0 是双目标信号自相消
3. **工程对策**：上游 MTD 阶段的多普勒过滤通常能检出反相多径（双目标速度不同）
