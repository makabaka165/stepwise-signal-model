## 2. 本轮实现

- 新建 step_08_7 层次三 minimal validation 目录。

- 实现 4 条 route：level2 rank1 baseline、level2 el-bank baseline、level3 2D FBSS-MUSIC、oracle el 2D rank1 covfit upper bound。
