## 理论背景

### 1. 单目标动态选列

设目标真实方位为 theta_target，阵元列方位集合为 phi_q，动态选列中心为最近列：

$$theta_c = nearest\_column(theta\_target)$$

则局部偏移为：

$$Delta\_theta = theta\_target - theta_c$$

若列间隔为 Delta_phi_col，则：

$$|Delta\_theta| <= Delta\_phi\_col / 2$$

本轮从 `arr_cyl` 生成的实际 XY 坐标反算列角，得到 Delta_phi_col = 1.875000000 deg，因此半列间隔为 0.937500000 deg。这个界只是单目标或目标中心的最近列吸附误差，不等于双目标场景中每个目标的最大偏移。

### 2. 双目标按融合中心选列

设 theta1 = theta0 - d/2，theta2 = theta0 + d/2。如果粗检测只有一个融合峰并接近 theta0，则 theta_c = nearest_column(theta0)。定义 delta = theta0 - theta_c，则 |delta| <= 0.937500000 deg。

两个目标相对中心列的偏移为：

$$Delta\_theta1 = delta - d/2$$

$$Delta\_theta2 = delta + d/2$$

因此局部搜索半宽至少需要满足：

$$R\_theta >= 0.937500000\ deg + d\_max/2 + epsilon\_coarse + epsilon\_margin$$

### 3. 双目标按强目标选列

如果幅度差较大，粗峰可能被强目标主导。若 theta_c = nearest_column(theta_strong)，强目标偏移满足 |Delta_theta_strong| <= 0.937500000 deg。若弱目标与强目标间隔为 d，则弱目标偏移可能达到：

$$|Delta\_theta\_weak| <= 0.937500000\ deg + d$$

因此局部搜索半宽需要满足：

$$R\_theta >= 0.937500000\ deg + d\_max + epsilon\_coarse + epsilon\_margin$$

### 4. 观测粗峰选列

工程中也可能先用低成本粗谱或波束扫描得到 theta_coarse = argmax P_coarse(theta)，再选 theta_c = nearest_column(theta_coarse)。theta_coarse 会随 beta、phase、rho、SNR 和 pair separation 改变。本轮 Part A 对 observed coarse peak 使用解析代理：

$$theta\_eff = (theta1 + beta\ theta2)/(1+beta)$$

并把 theta_eff 吸附到最近实际列；本轮未实现额外 beamformer simulated coarse peak，以避免把搜索范围验证扩展成新的粗测角算法实验。

### 5. 本轮核心问题

本轮验证 ±0.6 deg 是否足够、±1.0 deg 是否仅覆盖单目标吸附、±1.5 deg 是否覆盖 pair-center 双目标、±2.0 deg 是否覆盖 strong-target/粗中心偏置，并观察扩大 R 后 success、false-high、boundary-missed、runtime 和模板量的变化。

## 判断

- R=0.6 只适合理想 azCtr 已经很接近真实中心的仿真，不足以覆盖动态最近列选中心的双目标最坏情况。
- R=1.0 基本对应单目标最近列吸附量级，对双目标 pair-center 已不充分。
- R=1.5 对本轮 DOA 中 d<=0.8 deg 的等幅/融合中心双目标是较合理 runtime 默认范围；若几何 d_max 扩展到 1.2 deg，理论上还需要更宽余量。
- R=2.0 对本轮 strong-target d<=0.8 deg 场景更稳，可作为 canonical template 覆盖和低置信扩展范围。
- beta=0.3 弱目标仍属于 weak-target boundary；扩大搜索范围不能解决弱目标可辨识性，只能避免目标落出局部网格。
- large-el reference 用于确认扩大 R 没有破坏大俯仰差分支。

## 推荐策略

- FPGA canonical template Delta_theta 覆盖范围：R_template = 2.0 deg。
- MATLAB/runtime 默认搜索范围：R_runtime_default = 1.5 deg。
- runtime adaptive expansion：低置信或边界迹象时扩展到 R = 2.0 deg。
- 当前 ±0.6 deg 只保留为理想局部仿真范围，不建议作为工程动态选列默认范围。
- 本轮完成后可以进入定点量化验证，但需要在定点报告中保留 R_template 与 runtime ROI/扩展策略的区分。
