# 第7步三条路线说明

## 1. 文档目的

本文用于说明第 7 步当前保留的三条独立路线，以及它们共享的实验框架和各自保留的内部算法参数。

当前第 7 步不再保留单独的路线对比驱动脚本，而是保留三个可独立运行的入口：

1. `A0`：`space_smooth_music.m`
2. `A1`：`space_smooth_music_A1_eval.m`
3. `B`：`space_smooth_music_new_route_centerT.m`

这三条路线现在满足：

- 公共实验参数一致
- 数据生成方式一致
- 成功判据一致
- RMSE 统计方式一致
- 随机种子一致

同时：

- `A0 / A1 / B` 各自保留本路线内部算法参数
- 三条路线可单独运行、单独看趋势
- 如需横向比较，可直接比较三份日志和图

## 2. 当前涉及文件

### 2.1 三个独立入口脚本

1. `space_smooth_music.m`
   - Route A0
   - 复现原始旧 Route A 的受限搜索版本

2. `space_smooth_music_A1_eval.m`
   - Route A1
   - 用更一般的搜索设置验证 A0 是否可泛化

3. `space_smooth_music_new_route_centerT.m`

2. `DOA_three_music_hecheng_fangzhen_eval.m`

3. `DOA_three_music_new_route_centerT.m`
   - B 使用

### 2.3 公共辅助函数

1. `is_valid_doa_success.m`

## 3. 公共实验框架

三条路线统一使用下面这组公共实验参数。

| 参数 | 含义 | 当前值 |
|---|---|---:|
| `array_num` | 阵元数 | 64 |
| `fc` | 载频 | 2.7e9 Hz |
| `d` | 阵元间距 | 0.047 m |
| `theta_c` | 双目标中心角 | 13 deg |
| `snr` | 信噪比 | 12 dB |
| `Metkl` | Monte Carlo 次数 | 50 |
| `tol_deg` | 成功容差 | 0.1 deg |
| `T_snap_list` | 快拍数列表 | `[130, 260, 520]` |
| `bw_index_list` | 角间隔档位 | `1:10` |
| `rng` | 随机种子 | `20260515` |

### 3.1 角间隔档位

参考波束宽度定义为：

```matlab
bw_64 = 50.8 * 1.45 * lambda / (array_num - 1) / d;
bw_64 = roundn(bw_64, -1);
```

测试档位统一为：

```matlab
theta_bw = [bw_64/1, bw_64/2, bw_64/3, bw_64/4, bw_64/5, ...
            bw_64/6, bw_64/7, bw_64/8, bw_64/9, bw_64/10];
```

即：

- `bw/1`
- `bw/2`
- `bw/3`
- `bw/4`
- `bw/5`
- `bw/6`
- `bw/7`
- `bw/8`
- `bw/9`
- `bw/10`

### 3.2 双目标角度生成

对每个角间隔档位，真实双目标角度统一为：

```matlab
theta_a = theta_c - theta_sep / 2;
theta_b = theta_c + theta_sep / 2;
target_theta = [theta_a, theta_b];
```

### 3.3 数据生成方式

三条路线都使用同样的相干双目标数据生成方式：

```matlab
s1 = sqrt(10^(snr / 10)) * exp(j * 2 * pi * fc * t);
s2 = sqrt(10^(snr / 10)) * exp(j * 2 * pi * fc * t);
A_a = exp(-j * 2 * pi * d * (0:array_num-1) * sind(theta_a) / lambda);
A_b = exp(-j * 2 * pi * d * (0:array_num-1) * sind(theta_b) / lambda);
y = s11 + s21 + (1 / sqrt(2)) * (randn(array_num, T_snap) + j * randn(array_num, T_snap));
```

### 3.4 统一评价口径

三条路线统一使用：

1. `raw_success`
   - 只要求输出为有限值

2. `tol_success`
   - 使用 `is_valid_doa_success(doa_est, target_theta, tol_deg)`

3. `RMSE`
   - 只对有效样本统计
   - 误差定义为

```matlab
sqerr = sum((sort(doa_est(:).') - sort(target_theta(:).')).^2);
```

## 4. 三条路线各自保留的内部参数

公共实验框架统一，并不代表三条路线的内部算法参数必须完全相同。下面这些参数仍由各路线自己保留。

### 4.1 Route A0

脚本：`space_smooth_music.m`

内部参数：

- `routeA0_beam_span = bw_64`
- `M_old_A0 = 50`
- `theta_search_A0 = theta_sep`

特点：

- 搜索窗口宽度直接等于目标间隔
- 真实目标恰好落在搜索窗口边界
- 用于复现旧 Route A 的受限搜索结果

### 4.2 Route A1

脚本：`space_smooth_music_A1_eval.m`

内部参数：

- `search_scale_A1 = 4`
- `qSmoothRatio_A1 = 0.2`
- `routeA1_beam_span = 4 * bw_64`
- `M_old_A1 = round(search_scale_A1 * 50)`

特点：

- 搜索宽度与目标间隔解耦
- 使用 `DOA_three_music_hecheng_fangzhen_eval`
- 用于验证 A0 是否可以泛化到更一般搜索条件

### 4.3 Route B

脚本：`space_smooth_music_new_route_centerT.m`

内部参数：

- `search_scale_B = 4`
- `K_fbss = 56`
- `M_full = 48`
- `center_beam_count = 37`

特点：

- 先在阵元域构造协方差
- 再做 FBSS
- 再投影到 centerT 波束域后做 1D MUSIC

## 5. 当前推荐的使用方式

### 5.1 单独看某条路线

如果只想看某条路线内部趋势，直接运行对应脚本即可：

- `A0`：`space_smooth_music.m`
- `A1`：`space_smooth_music_A1_eval.m`
- `B`：`space_smooth_music_new_route_centerT.m`

### 5.2 做路线间横向比较

当前不再保留专门的路线对比驱动脚本。

如需横向比较，直接对照三份脚本输出的：

- 日志文件
- 成功率曲线
- RMSE 曲线

由于三者已经使用统一的实验框架，因此这类比较现在是可解释的。

## 6. 当前结构的意义

当前第 7 步的结构可以概括为：

1. `A0` 负责复现旧受限搜索路线
2. `A1` 负责验证 A0 的稳健性和可泛化性
3. `B` 作为当前正式主线方案

这三个入口既保留了各自算法特征，又避免了过去“每条路线脚本各自使用不同实验设置，难以直接比较”的问题。

---

## 7. 结论

截至当前版本，第 7 步的代码组织原则是：

> 三条路线分别保留独立入口，共享同一套公共实验框架，各自保留本路线内部算法参数。

这样做的好处是：

1. 每条路线都能单独运行、单独分析
2. 三条路线又能在统一实验口径下进行结果对照
3. 后续如果需要继续改进某一路线，不会破坏另外两条路线的独立可读性
