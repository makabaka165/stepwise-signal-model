# 第 1 步：验证 FBSS 构造是否正确

## 目标

验证下面两种 FBSS 构造方式是否等价：

方式 A：先算阵元域协方差，再对子块平均：

[
R_x=\frac{1}{T}YY^H
]

[
R_f=
\frac{1}{P}
\sum_{p=1}^{P}
J_p R_x J_p^H
]

方式 B：直接对子阵快拍做协方差平均：

[
R_f=
\frac{1}{PT}
\sum_{p=1}^{P}
(J_pY)(J_pY)^H
]

理论上两者应该一致。

------

## 新增文件 1：`mssp_array_fb_from_snapshots.m`

放到：

```text
stepwise_signal_model/steps/step_07_space_smooth_music/mssp_array_fb_from_snapshots.m
```

内容：

```matlab
function Rfbss = mssp_array_fb_from_snapshots(Y, K)
    % 从快拍子阵数据直接构造阵元域 FBSS 协方差。
    %
    % 输入：
    %   Y : N x T 阵元域快拍
    %   K : 子阵长度，必须 K < N
    %
    % 输出：
    %   Rfbss : K x K 前后向空间平滑协方差

    [N, T] = size(Y);

    if K >= N
        error('K must be smaller than N.');
    end

    if K < 2
        error('K must be at least 2.');
    end

    P = N - K + 1;

    Rf = zeros(K, K);
    for p = 1:P
        idx = p:p+K-1;
        Yp = Y(idx, :);
        Rf = Rf + (Yp * Yp') / T;
    end
    Rf = Rf / P;

    J = fliplr(eye(K));
    Rfbss = 0.5 * (Rf + J * conj(Rf) * J);
    Rfbss = 0.5 * (Rfbss + Rfbss');
end
```

------

## 在诊断脚本里加对比

在生成 `y` 之后加入：

```matlab
K = 48;

Rxx = y * y' / size(y, 2);

Rss_block = mssp_array_fb(Rxx, K);
Rss_snap  = mssp_array_fb_from_snapshots(y, K);

rel_err = norm(Rss_block - Rss_snap, 'fro') / norm(Rss_block, 'fro');

fprintf('FBSS block-vs-snapshot relative error = %.3e\n', rel_err);
```

------

## 预期结果

正常应当是：

```text
rel_err ≈ 1e-12 ~ 1e-10
```

如果结果接近这个量级，说明：

```text
当前 FBSS 构造方式没问题
```

如果 `rel_err` 很大，比如：

```text
1e-3, 1e-2, 1e-1
```

那就先不要继续后面步骤，先检查：

1. `mssp_array_fb.m` 是否用了 `conj(Rf)`；
2. 是否用了同一个 `K`；
3. `Rxx = y*y'/T` 是否写对；
4. `Yp = y(idx,:)` 是否按行截取子阵。

function [doa_value, debug] = DOA_direct_music_from_Rss(Rss, K, angle_recv, theta_bw, varargin)
    % 直接在 K x K 的阵元域 FBSS 协方差 Rss 上做 MUSIC。
    %
    % 输入：
    %   Rss        K x K 阵元域 FBSS 协方差
    %   K          子阵长度
    %   angle_recv 搜索中心角，degree
    %   theta_bw   搜索宽度，degree
    %
    % 可选：
    %   Lc         目标数，默认 2

    p = inputParser;
    addParameter(p, 'Lc', 2);
    parse(p, varargin{:});
    Lc = p.Results.Lc;

    j = sqrt(-1);
    c = 3e8;
    fc = 2.7e9;
    lambda = c / fc;
    d = 0.047;

    Rss = 0.5 * (Rss + Rss');

    [E, D] = eig(Rss);
    eigvals = real(diag(D));
    [eigvals, idx] = sort(eigvals, 'descend');
    E = E(:, idx);

    if size(E, 2) <= Lc
        doa_value = nan(1, Lc);
        debug = struct();
        return;
    end

    En = E(:, Lc+1:end);

    posK = d * (0:K-1).';
    angle_search = angle_recv - theta_bw/2 : 0.01 : angle_recv + theta_bw/2;

    Pmu = zeros(1, numel(angle_search));

    for ii = 1:numel(angle_search)
        theta = angle_search(ii);
        aK = exp(-j * 2*pi/lambda * posK * sind(theta));

        den = real(aK' * En * En' * aK);
        num = real(aK' * aK);

        Pmu(ii) = num / max(den, eps);
    end

    [~, peak_ind] = FindLocalPeak_Fun(abs(Pmu));

    if numel(peak_ind) < Lc
        doa_value = nan(1, Lc);
    else
        doa_value = sort(angle_search(peak_ind(1:Lc)));
    end

    debug.angle_search = angle_search;
    debug.spectrum = Pmu;
    debug.eigvals = eigvals;
end
```

function diag_info = diagnose_rss_eigs(Rss, Lc)
    % 诊断 FBSS 协方差的信号/噪声特征值分离情况。

    Rss = 0.5 * (Rss + Rss');

    eigvals = sort(real(eig(Rss)), 'descend');

    n_eig = numel(eigvals);

    noise_start = Lc + 1;
    noise_end = min(n_eig, Lc + 6);

    if noise_start <= noise_end
        noise_floor = mean(eigvals(noise_start:noise_end));
    else
        noise_floor = nan;
    end

    diag_info.eigvals = eigvals;
    diag_info.lambda1 = eigvals(1);

    if n_eig >= 2
        diag_info.lambda2 = eigvals(2);
    else
        diag_info.lambda2 = nan;
    end

    diag_info.noise_floor = noise_floor;
    diag_info.lambda2_over_noise = diag_info.lambda2 / noise_floor;
    diag_info.lambda1_over_lambda2 = diag_info.lambda1 / diag_info.lambda2;
end
```

## 新增文件 4：`pick_two_peaks_fallback.m`

路径：

```text

```

内容：

```matlab
function doa_value = pick_two_peaks_fallback(angle_search, Pmu, Lc)
    % 先用原 FindLocalPeak_Fun。
    % 如果局部峰不足，再用左右分区最大值作为 fallback。
    %
    % 该函数只建议用于诊断，不建议直接作为主算法结论。

    Pmu = abs(Pmu);

    [~, peak_ind] = FindLocalPeak_Fun(Pmu);

    if numel(peak_ind) >= Lc
        doa_value = sort(angle_search(peak_ind(1:Lc)));
        return;
    end

    if Lc ~= 2
        doa_value = nan(1, Lc);
        return;
    end

    [~, imax] = max(Pmu);

    guard = 3;

    left_idx = 1:max(1, imax-guard);
    right_idx = min(numel(Pmu), imax+guard):numel(Pmu);

    if isempty(left_idx) || isempty(right_idx)
        doa_value = nan(1, Lc);
        return;
    end

    [~, il_local] = max(Pmu(left_idx));
    [~, ir_local] = max(Pmu(right_idx));

    idx_left = left_idx(il_local);
    idx_right = right_idx(ir_local);

    if idx_left == idx_right
        doa_value = nan(1, Lc);
        return;
    end

    doa_value = sort([angle_search(idx_left), angle_search(idx_right)]);
end
```

------

## 怎么用

不要马上替换主函数。先在 direct MUSIC 或 beamspace MUSIC 的 debug 结果上离线测试：

```matlab
doa_fallback = pick_two_peaks_fallback( ...
    debug_beam.angle_search, debug_beam.spectrum, 2);
```

或者：

```matlab

    debug_direct.angle_search, debug_direct.spectrum, 2);
```

------

## 判断标准

如果 fallback 后：

```text
success 明显提升，RMSE 仍然小
```

说明：

```text
原 peak picking 太严格
```

可以考虑修改最终峰值检测。

如果 fallback 后：

```text
success 提升，但 RMSE 很大
```

说明：

```text
谱上其实没有稳定双峰，fallback 只是强行找两个点
```

如果 fallback 后：

```text
success 也没有明显提升
```

说明：

```text
失败不是峰值检测问题，而是谱确实塌成单峰
```

# 第 5 步：加 ESPRIT 对照

## 目标

验证失败是否来自 grid MUSIC + 峰值检测，而不是子空间本身。

FBSS 后的 (R_{\mathrm{ss}}) 是 (K \times K) ULA 子阵协方差，可以直接做 ESPRIT。

------

## 新增文件 5：`doa_esprit_from_Rss.m`

路径：

```text
stepwise_signal_model/steps/step_07_space_smooth_music/doa_esprit_from_Rss.m
```

内容：

```matlab
function doa_value = doa_esprit_from_Rss(Rss, K, Lc, angle_center, search_bw)
    % 在 K x K 的 FBSS 协方差上做 ESPRIT。
    %
    % 输入：
    %   Rss          K x K FBSS 协方差
    %   K            子阵长度
    %   Lc           目标数
    %   angle_center 搜索中心角，degree
    %   search_bw    搜索宽度，degree
    %
    % 输出：
    %   doa_value    长度 Lc；若有效估计不足则返回 NaN

    c = 3e8;
    fc = 2.7e9;
    lambda = c / fc;
    d = 0.047;

    Rss = 0.5 * (Rss + Rss');

    [E, D] = eig(Rss);
    eigvals = real(diag(D));
    [~, idx] = sort(eigvals, 'descend');
    E = E(:, idx);

    if size(E, 2) < Lc
        doa_value = nan(1, Lc);
        return;
    end

    Es = E(:, 1:Lc);

    Es1 = Es(1:K-1, :);
    Es2 = Es(2:K, :);

    Phi = pinv(Es1) * Es2;
    z = eig(Phi);

    % 当前 steering 约定为 exp(-j * mu * n)，所以 z = exp(-j * mu)
    mu_hat = -angle(z);

    sin_theta = mu_hat * lambda / (2*pi*d);

    valid = abs(sin_theta) <= 1;
    theta_hat = asind(real(sin_theta(valid)));

    low = angle_center - search_bw/2;
    high = angle_center + search_bw/2;

    in_win = theta_hat(theta_hat >= low & theta_hat <= high);

    if numel(in_win) < Lc
        doa_value = nan(1, Lc);
        return;
    end

    % 若多于 Lc 个，取最靠近搜索中心的 Lc 个
    [~, order] = sort(abs(in_win - angle_center), 'ascend');
    selected = in_win(order(1:Lc));

    doa_value = sort(selected(:).');
end
```
