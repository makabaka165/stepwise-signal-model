# 第7步 A0/A1/B 结果分析说明

## 1. 文档目的

本文用于记录第 7 步三条路线在统一实验框架下的现象解释，重点回答：

1. 为什么 `A0` 容易出现边界型命中
2. 为什么 `A1` 在取消边界先验后明显变差
3. 为什么 `B` 的趋势更接近通常的 DOA 分辨直觉

当前代码结构已经改为三个独立入口：

- `A0`: `space_smooth_music.m`
- `A1`: `space_smooth_music_A1_eval.m`
- `B`: `space_smooth_music_new_route_centerT.m`

本文不再依赖已删除的专门对比脚本。

---

## 2. 当前统一实验框架

三条路线已经统一：

- 相同的双目标角度生成方式
- 相同的 `snr = 12`
- 相同的 `T_snap_list = [130, 260, 520]`
- 相同的 `Metkl = 50`
- 相同的数据生成方式
- 相同的成功判据 `is_valid_doa_success(...)`
- 相同的 RMSE 统计方式
- 相同的随机种子 `rng(20260515, 'twister')`

因此现在比较三条路线时，差异主要来自算法内部设计，而不是实验口径不一致。

---

## 3. A0 的现象与原因

`A0` 的核心设置是：

```matlab
theta_search_A0 = theta_sep;
```

在当前双目标构造中：

```matlab
theta_a = theta_c - theta_sep / 2;
theta_b = theta_c + theta_sep / 2;
```

因此 `A0` 的搜索区间正好是：

```text
[theta_a, theta_b]
```

也就是说，真实目标天然落在搜索窗口边界上。

这会带来两个结果：

1. `A0` 很容易出现边界型命中
2. 一旦输出接近左右边界，`RMSE` 会显得非常小

所以 `A0` 的高成功率和低误差并不能直接解释为“在一般搜索条件下具有强超分辨能力”，它更像是：

> 在强先验搜索边界约束下复现旧代码现象的启发式路线。

---

## 4. A1 的现象与原因

`A1` 保留了和 `A0` 相近的 beam grid 密度，但将搜索宽度改为：

```matlab
theta_search_A1 = 4 * theta_sep;
```

这样一来，真实目标不再卡在搜索窗口边界，而是落在搜索区间内部。

`A1` 的作用不是提出一条更强的新路线，而是验证：

> 如果去掉 A0 对搜索边界的强先验，旧的 beam-index smoothing 路线是否仍然稳健。

如果 `A0` 的成功来自一般性的测角能力，那么 `A1` 在更宽搜索区间内仍应能稳定找到两个真实峰。  
如果 `A1` 显著退化，则说明 `A0` 的成功高度依赖边界先验。

因此 `A1` 的价值主要是诊断与验证，而不是作为最终主线算法。

---

## 5. B 的现象与原因

`B` 的核心路线是：

```text
阵元域协方差 -> FBSS -> centerT 投影 -> 1D MUSIC
```

它的搜索宽度设置为：

```matlab
theta_search_B = 4 * theta_sep;
```

因此与 `A0` 不同，`B` 也不具有“目标天然贴边界”的优势。

在这种情况下，`B` 要想成功，就必须在搜索区间内部真的形成两个可分离的局部峰。  
这使得它的趋势通常更符合常见 DOA 分辨规律：

- 目标间隔越大，越容易分开
- 快拍数越多，协方差估计越稳定
- 小间隔时更容易退化

所以 `B` 的曲线一般比 `A0` 更接近物理直觉。

---

## 6. 为什么三条路线仍然允许内部参数不同

虽然公共实验框架已经统一，但三条路线内部参数仍然不同，例如：

- `A0` 用 `theta_search_A0 = theta_sep`
- `A1` 用 `search_scale_A1 = 4`、`QSmoothRatio_A1 = 0.2`
- `B` 用 `K_fbss = 56`、`M_full = 48`、`center_beam_count = 37`

这是正常的，因为这些参数属于各路线自己的算法设计，不属于公共实验口径。

真正需要统一的是：

1. 题目是什么
2. 数据怎么生成
3. 成功怎么判
4. RMSE 怎么算

只要这四类东西一致，三条路线即使内部参数不同，仍然可以比较。

---

## 7. 当前最合理的解释框架

第 7 步现在可以这样理解：

- `A0`：旧路线复现实验
- `A1`：稳健性验证路线
- `B`：当前正式主线

因此：

1. `A0` 的意义主要是复现和问题暴露
2. `A1` 的意义主要是证明 A0 不能泛化
3. `B` 更适合作为论文或后续实现的主路线

---

## 8. 使用建议

当前更推荐的分析方式是：

1. 先单独看每条路线自己的趋势
2. 再在统一实验框架下横向比较三条路线的日志和图

这样既保留了三条路线各自的可读性，也避免了过去“脚本彼此实验口径不同，导致比较不稳”的问题。
