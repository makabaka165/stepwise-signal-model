# 第8.11步 shared-center增强测角最终路线收束报告

## 1. 本轮定位

本轮目标是最终路线收束，不再继续算法发散。当前最新有效基线为 `8b4d3c6` 之后的第 8.10 结果：统一模型选择验证失败，不建议替代第 8.7 cascade。因此本文最终主线回到：

`前端检测 -> shared-center 选阵 -> Y_work 构造 -> 第 8.7 剪枝版 cascade 增强测角 -> 置信输出`

本文最终主线不是普适 MUSIC 改进算法、全场多目标动态调度算法、dual-center 多粗峰处理算法、完整 FPGA 定点硬化实现，也不是第 8.10 统一模型选择替代算法。

本文最终主线是：**面向全息凝视圆柱阵 single coarse peak / unresolved local cluster 的 shared-center 局部增强测角链路。**

## 2. 正确系统表述

必须避免写成“先在全阵检测到粗峰后才第一次选 65 列”。更严谨的表述是：

系统首先由扇区调度、粗搜索或跟踪预测确定当前观测扇区，并据此选取 65 列工作子阵；在该工作子阵内完成前端检测、粗测角和局部状态判断；第 8.8 / 第 8.7 处理的是该局部工作子阵内的 `single coarse peak / unresolved local cluster`。

正式适用场景：

1. 上游扇区中心、调度中心或跟踪预测中心给出当前观测扇区；
2. 系统围绕该中心选取 65 列工作子阵；
3. 在 65 列工作子阵内完成 LFM、脉压、MTD、CFAR 和粗测角；
4. 前端得到 single coarse peak 或 unresolved local cluster；
5. 该粗峰可能包含一个目标，也可能包含两个相干或近邻空间分量；
6. 系统构造 `Y_work`；
7. 进入 shared-center 增强测角；
8. 输出单目标、双目标或 `low_confidence / boundary_unreliable`。

## 3. 已有结果摘要

### 第 8.7 / 7B

第 8.7 7B 是当前工程 runtime 主线。记录显示：

- `lazy_success_rate_all = 0.731373`；
- `lazy_false_high_confidence_rate_all = 0`；
- `lazy_boundary_missed_rate_all = 0`；
- `mean_runtime_reduction_all = 0.35934`；
- `execution_rate_2dmusic_all = 0.581046`；
- `execution_rate_pair_local_all = 0.352941`；
- large-el 场景 `large_el_lazy_success_rate = 1`。

这说明剪枝版 cascade 在安全性上闭合，同时保留了明显的 runtime reduction。

### 第 8.8 / 8.8B

第 8.8 打通了前端检测到第 8.7 shared-center 增强测角的接口闭环：

- `cfar_detection_rate_overall = 1`；
- `single_coarse_peak_rate_overall = 0.916667`；
- `two_coarse_peak_rate_overall = 0.0833333`，该部分标记为 out-of-scope；
- `in_scope_shared_center_rate = 0.916667`；
- `center_selection_success_rate_overall = 0.916667`；
- `false_high_rate_in_scope = 0`；
- `boundary_missed_rate_in_scope = 0`。

第 8.8B 表明 `no_derotation`、`derotation_minus`、`derotation_plus` 的 route、confidence、success 与输出一致，推荐默认 `recommended_ywork_mode = no_derotation_or_optional_derotation`，不强制启用 Doppler de-rotation。

### 第 8.9

第 8.9 系列是定点敏感性与硬件移植边界分析：

- float32 基本可用；
- 统一 fixed-point / mixed precision 没有闭合；
- 第 8.9B 显示主要敏感源是 steering/template/cache 系数量化，而不是 `Y_work`；
- 第 8.9D 的 margin-aware / candidate-tie guard 未能降低 worst-case；
- 第 8.9E 显示分叉集中在 refocus-rank1 判据、score-gap 和 pair-sep 等边界翻转；
- 当前不建议直接进入完整 FPGA kernel design。

### 第 8.10

第 8.10 统一模型选择验证不建议替代 cascade：

- `unified_success_overall = 0.0850291`，明显低于 `cascade_success_overall = 0.494186`；
- `success_gap_unified_vs_cascade = -0.409157`；
- `unified_false_high = 0.222384`；
- `unified_boundary_missed = 0.0363372`；
- single target H1 rate 为 0，large-el H3 rate 为 0，模型选择分布不符合物理预期；
- 结论为 `recommended_final_route = keep_cascade`。

因此第 8.10 只保留为理论解释尝试和负结果，用于说明为什么最终保留工程 cascade。

## 4. 最终剪枝版算法

最终保留以下分支：

- Branch A：常规 MUSIC 可分辨。level2 / MUSIC 谱稳定给出可靠双峰时输出 MUSIC 结果。
- Branch B：强相干近邻 fallback。MUSIC 单峰或双峰合并时，执行 common-el refocus + rank1 fallback，是 close coherent pair 的主力。
- Branch C：二维分离分支。俯仰差明显或层次二压缩不适用时，执行 2D MUSIC / pair-local refinement，是 large-el 场景主力。
- Branch D：边界保护。观测不支持可靠输出时，输出 `low_confidence / boundary_unreliable`。

## 5. 舍弃与降级路线

| 路线 | 结论 | 最终定位 |

## 6. 论文创新点建议

1. **前端检测驱动的 shared-center 局部增强测角框架**：面向全息凝视圆柱阵 single coarse peak / unresolved local cluster 场景，将 LFM、脉压、MTD、CFAR、粗测角与局部增强测角接口打通。
2. **动态 65 列工作子阵与局部 steering 模板**：基于 nearest-column shared-center 选阵和局部 `Delta theta` 坐标，验证 canonical local template 可复用，支持 FPGA 友好的 steering 预计算。
3. **保守级联增强测角与边界保护**：在常规 MUSIC、strong coherent rank1 fallback、large-el 2D 分支之间进行保守分流，并对 weak-target、anti-phase、multi-coarse-peak 等边界场景输出低置信或 out-of-scope，避免高置信误报。

推荐论文表述为：**提出一种面向全息凝视圆柱阵局部未分辨目标簇的 shared-center 增强测角链路。**

不要写成“提出普适相干源 MUSIC 改进算法”。
